# 📌 [TIL] n8n을 활용한 날씨 & 운세 디스코드 자동화 봇 제작

> 💡 **학습 목표:** n8n, Open-Meteo API, AI Agent, Discord Webhook을 연동하여 매일 아침 개인화된 날씨 및 운세 알림 자동화 시스템을 구축한다.

---

## 🛠️ 1. 워크플로우 흐름 및 노드 연결 (Workflow Architecture)

`Schedule Trigger` ➔ `HTTP Request` ➔ `Edit Fields (Set)` ➔ `AI Agent` ➔ `Discord`

* **Schedule Trigger**: 매일 지정된 시간(09:20 KST)에 자동 실행
* **HTTP Request**: Open-Meteo API를 호출하여 서울시 강남구 좌표 기반 현재 날씨 조회
* **Edit Fields (Set)**: 날씨 데이터 정제 + 개인 정보(이름, 띠, 별자리, 날짜) 변수 구조화
* **AI Agent**: 정제된 데이터를 받아 디스코드용 마크다운 형식의 운세/명언 문장 생성
* **Discord (Webhook)**: AI가 생성한 최종 메시지를 디스코드 채널로 자동 발송

---

## 📖 2. n8n 노드별 핵심 & 부기능 필기노트

### ⏰ 1) Schedule Trigger (스케줄 트러거)
* **주기능:** 특정 주기(일/주/월) 또는 정해진 시간대에 워크플로우 자동 실행
* **핵심 체크:** 실행 시간 설정 시 타임존이 `Asia/Seoul`로 세팅되어 있는지 확인 필수

### 🌐 2) HTTP Request (날씨 API 연동)
* **주기능:** 외부 REST API와 연동하여 데이터 수신(GET) 또는 발송(POST)
* **핵심 체크:** URL 작성 시 `Query Parameters` 옵션을 켜고 위도(`latitude`), 경도(`longitude`), 속성(`current`)을 분리 지정하여 관리

### ✏️ 3) Edit Fields / Set (데이터 가공 & 변수 정의)
> 🌟 **이번 프로젝트의 가장 핵심적인 데이터 전처리 노드!**
* **주기능:** 복잡한 이전 노드의 JSON 구조에서 필요한 데이터만 추출하거나 새로운 변수/수식 정의
* **부기능:** Expressions (자바스크립트 수식) 기능 활용
  * **날짜 생성:** `$now.setZone('Asia/Seoul').toFormat('yyyy년 MM월 dd일')`
  * **한글 요일 고정:** `['일', '월', '화', '수', '목', '금', '토'][$now.weekday % 7] + '요일'`
* **꿀팁:** `Keep Only Set Fields` 옵션을 켜두면 불필요한 원본 데이터를 지워 AI Agent에 깔끔한 값만 넘길 수 있음

### 🤖 4) AI Agent (LLM 연결 및 문장 생성)
* **주기능:** Open AI, Anthropic 등의 LLM을 연동하여 프롬프트 지침에 맞게 텍스트 가공 및 생성
* **핵심 체크:** AI Agent에는 순수 **지시사항(Prompt / User Message)**만 전달하고, 기초 데이터는 이전 노드(`Edit Fields`)에서 완전히 정리해서 넘겨주는 것이 유지보수에 유리함

### 💬 5) Discord Webhook (알림 발송)
* **주기능:** 디스코드 채널의 Webhook URL을 통해 메시지 수신
* **부기능:** 디스코드 기본 마크다운 지원 (`#` 제목, `**` 굵게, `>` 인용구, 이모지 등)

## 💡 3. 실전 트러블슈팅 노트 (이슈 & 해결)

### ❓ Issue 1. 날씨 데이터 자리에 `[object Object]` 오류 출력
* **원인:** Open-Meteo API의 JSON 객체 전체를 프롬프트에 통째로 바인딩 시 텍스트 변환 오류 발생
* **해결:** `Edit Fields` 노드를 중간에 추가하여 `temperature_2m` ➔ `temperature`처럼 단일 수치값(Primitive Value)으로 깔끔하게 매핑 후 넘겨줌

### ❓ Issue 2. 날짜 표현 시 요일이 영어(`Thursday`)로 표시되는 현상
* **원인:** n8n 기본 언어 포맷(Luxon)이 영문 기반이라 `cccc`가 영어 요일을 출력
* **해결:** `Edit Fields` 수식에서 자바스크립트 배열 인덱싱 수식 `['일', '월', '화', '수', '목', '금', '토'][$now.weekday % 7]`을 조합해 한국어 요일로 고정

### ❓ Issue 3. Structured Output Parser 사용 시 디스코드 출력 스타일 깨짐
* **원인:** Output Parser는 AI에게 `JSON` 형태만 뱉도록 강제하므로, 마크다운이 적용되어야 하는 디스코드 텍스트 형식과 충돌
* **해결:** Parser 노드를 제거하고, **AI Agent의 User Message** 안에 디스코드 마크다운 작성 지침을 직접 포함시켜 가독성 확보

### ❓ Issue 4. 디스코드 제목의 날짜와 위치 줄바꿈 미적용
* **원인:** 한 줄 형태의 제목 작성 가이드로 인해 한 줄로 연속 출력됨
* **해결:** AI 프롬프트 작성 가이드 1번에 `# 🗓️ {{ $json.today_date }}` 작성 후 줄바꿈하여 `## 📍 {{ $json.location }}`을 적용하도록 지시문 정교화
