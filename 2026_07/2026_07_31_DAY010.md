# 🌐 웹 브라우저에 URL을 입력하면 일어나는 일

## 💡 예시

`https://google.com` 을 웹 브라우저에 입력하고 Enter를 누르면?

### 1️⃣ 브라우저가 주소를 확인

브라우저는 입력한 URL을 분석한다.

```text
https://google.com
```

* `https` → 프로토콜
* `google.com` → 도메인

---

### 2️⃣ 도메인을 IP 주소로 변환

컴퓨터는 `google.com`이라는 이름만으로 서버를 찾을 수 없다.

그래서 **DNS**를 이용해서

```text
google.com
↓
IP 주소
```

로 변환한다.

📌 DNS = 도메인 이름을 IP 주소로 찾아주는 시스템

---

### 3️⃣ 서버에 요청(Request)을 보냄

웹 브라우저는 **클라이언트(Client)** 역할을 한다.

```text
클라이언트(브라우저)
        ↓ Request
구글 서버(Server)
```

예를 들어 웹 페이지를 가져올 때는 보통 **GET 요청**을 사용한다.

---

### 4️⃣ 서버가 응답(Response)을 보냄

서버는 요청을 처리한 뒤 결과를 브라우저에게 보낸다.

응답에는 보통 다음이 포함된다.

* HTML
* CSS
* JavaScript
* 이미지 등의 데이터
* Status Code

---

### 5️⃣ 브라우저가 화면을 만들어 보여줌

브라우저는 서버에서 받은 HTML, CSS, JavaScript 등을 해석하고
**렌더링(Rendering)** 해서 우리가 볼 수 있는 웹 페이지로 보여준다.

```text
URL 입력
→ DNS로 IP 찾기
→ 서버에 Request
→ 서버에서 Response
→ 브라우저 Rendering
→ 웹 페이지 표시
```

---

# 📡 HTTP 요청 Method

## 🔹 GET

서버에서 **데이터를 가져올 때** 사용

```text
GET /products
```

예시

* 게시글 조회
* 상품 조회
* 검색 결과 조회

📌 의미
👉 "이 데이터 주세요!"

---

## 🔹 POST

서버에 데이터를 보내서 **새로운 데이터를 생성하거나 처리할 때** 사용

```text
POST /users
```

예시

* 회원가입
* 게시글 작성
* 로그인 정보 전달

📌 의미
👉 "이 데이터를 처리해주세요!"

---

# 🔗 URL 구조

예시

```text
https://example.com/products?id=10
```

구조

```text
https://example.com/products?id=10
│       │          │       │
프로토콜   도메인      Path    Query
```

### 주요 구성 요소

* 🌐 Protocol → `https`
* 🏠 Domain → `example.com`
* 📂 Path → `/products`
* 🔎 Query → `?id=10`
* 💾 Value → `10`

---

# 📩 Response

서버가 클라이언트에게 보내는 응답

```text
Request
클라이언트 ─────────▶ 서버

Response
클라이언트 ◀───────── 서버
```

응답에는 **Status Code(상태 코드)** 가 포함된다.

---

# 🚦 HTTP Status Code

## ✅ 200번대 — 성공

### `200 OK`

요청 성공

```text
GET 요청 성공
→ 200 OK
```

### `201 Created`

새로운 데이터 생성 성공

```text
POST로 회원 생성 성공
→ 201 Created
```

---

## ⚠️ 400번대 — Client Error

클라이언트가 보낸 요청에 문제가 있는 경우

### `400 Bad Request`

잘못된 요청

예:

* 잘못된 데이터 형식
* 필요한 값 누락

### `404 Not Found`

요청한 페이지나 데이터를 찾을 수 없음

---

## 🚨 500번대 — Server Error

서버 내부에서 문제가 발생한 경우

### `500 Internal Server Error`

예:

* 서버 코드 오류
* 서버 내부 처리 실패

---

# ⭐ 오늘 핵심 요약

```text
브라우저 = Client
서버 = Server

브라우저
   ↓ Request
서버
   ↓ Response
브라우저
   ↓ Rendering
웹 페이지 출력
```

### HTTP Method

```text
GET  → 데이터 가져오기
POST → 데이터 보내기 / 생성 / 처리
```

### Status Code

```text
200 → 성공
201 → 생성 성공

400 → 잘못된 요청
404 → 찾을 수 없음

500 → 서버 오류
```

### 웹사이트 접속 과정

```text
URL 입력
→ DNS로 IP 확인
→ 서버에 요청
→ 서버 응답
→ 브라우저 렌더링
→ 화면 출력
```
