# Database & SQL Basics

데이터베이스의 기본 구조와 관계형 모델, ERD, PostgreSQL 기반 SQL 기본 문법을 학습했다.

## Database Basics

- **Database**: 구조화된 데이터의 집합
- **DBMS**: 데이터를 저장·조회·수정·삭제하는 관리 시스템
- 대표 DBMS: PostgreSQL, MySQL, Oracle, SQLite

### Relational Database

관계형 데이터베이스는 데이터를 Table 형태로 저장한다.

```text
Table
├── Row: 데이터 한 건
└── Column: 데이터의 속성
```

### Key

- **Primary Key(PK)**: 각 Row를 고유하게 식별
- **Foreign Key(FK)**: 다른 Table의 PK 또는 UNIQUE Key를 참조

## Relationships

### 1:N

```text
Customer 1 ─── N Orders
```

### M:N

연관 테이블을 사용해 두 개의 1:N 관계로 분해한다.

```text
Student ─< Enrollment >─ Course
```

### 1:1

한 Row가 상대 Table의 최대 한 Row와 연결된다.

```text
Order ─── Refund
```

---

## Schema & ERD

**Schema**는 Table, Column, Data Type, Key, Constraint 등 데이터베이스 구조를 정의한다.

**ERD(Entity-Relationship Diagram)**는 Entity와 Relationship을 시각적으로 표현한다.

주요 요소:

- Entity
- Attribute
- Primary Key
- Foreign Key
- Relationship

# SQL

수업 예제는 PostgreSQL을 기준으로 학습했다.

## SQL Command Types

| Type | Commands |
|---|---|
| DDL | CREATE, ALTER, DROP, TRUNCATE |

## Transaction

여러 SQL 작업을 하나의 논리적인 작업 단위로 처리한다.

```text
BEGIN
↓
SQL 작업
↓
COMMIT / ROLLBACK
```

## CREATE TABLE

```sql
CREATE TABLE student (
    id VARCHAR(7) PRIMARY KEY,
    name VARCHAR(10),
    grade INT,
    major VARCHAR(20)
);
```

### 주요 Data Types

- INT
- BIGINT
- DECIMAL
- DOUBLE PRECISION
- CHAR
- VARCHAR
- TEXT
- DATE
- TIME
- TIMESTAMP
- BOOLEAN

### Constraints

- PRIMARY KEY
- NOT NULL
- UNIQUE
- CHECK
- FOREIGN KEY

```sql
student_id VARCHAR(7) REFERENCES student(id)
```

## ALTER TABLE

```sql

```

```sql

RENAME COLUMN phone TO phone_number;
```

```sql
ALTER TABLE student
DROP COLUMN phone_number;
```

---

## DML

### INSERT

```sql
INSERT INTO student (id, name, grade, major)
VALUES ('2024001', '김철수', 1, '컴퓨터공학');
```

### SELECT

```sql
SELECT *
FROM student;
```

### UPDATE

```sql
UPDATE student
SET grade = 2
WHERE id = '2024001';
```

### DELETE

```sql
DELETE FROM student
WHERE id = '2024002';
```

`UPDATE`, `DELETE`에서 `WHERE`을 생략하면 모든 Row가 대상이 될 수 있으므로 주의한다.

# SELECT

기본 구조:

```sql
SELECT [DISTINCT] column
FROM table
[WHERE condition]
[ORDER BY column ASC | DESC]
[LIMIT N]
[OFFSET M];
```

## Alias

```sql
SELECT c.name AS country_name
FROM country AS c;
```

## DISTINCT

```sql
SELECT DISTINCT continent
FROM country;
```

---

## WHERE

### Comparison

```sql
WHERE population > 1000000
WHERE population >= 1000000
WHERE population = 1000000
WHERE population != 1000000
```

### Logical Operators

```sql
WHERE population > 1000000
  AND (continent = 'Asia' OR continent = 'Europe');
```

### BETWEEN

```sql
WHERE population BETWEEN 1000000 AND 2000000
```

### IN

```sql
WHERE code IN ('KOR', 'JPN', 'CHN')
```

### NULL

```sql
WHERE lifeexpectancy IS NULL
```

```sql
WHERE lifeexpectancy IS NOT NULL
```

### LIKE

```sql
WHERE name LIKE 'S%'
WHERE name LIKE '%on'
WHERE name LIKE '%on%'
```

PostgreSQL의 `ILIKE`는 대소문자를 구분하지 않는 패턴 검색에 사용할 수 있다.

## ORDER BY

```sql
SELECT name, population
FROM city
ORDER BY population DESC;
```

여러 Column도 순서대로 정렬할 수 있다.

```sql
ORDER BY code, population DESC;
```

NULL 위치 지정:

```sql
ORDER BY indepyear DESC NULLS LAST;
```

---

## LIMIT / OFFSET

```sql
SELECT name, population
FROM city
ORDER BY population DESC
LIMIT 5;
```

```sql
SELECT name, population
FROM city
ORDER BY population DESC
LIMIT 5 OFFSET 10;
```

Pagination 계산:

```text
OFFSET = (page - 1) × page_size
```
