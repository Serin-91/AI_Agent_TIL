# AI Agent Study — MCP & Local LLM

## 36. Model Context Protocol (MCP)

[실습 노트북](https://drive.google.com/file/d/1ha6g32NXvmYe-We8LBgx2VaVMOpovB79/view)

### 핵심 개념

MCP는 AI 애플리케이션과 외부 도구·데이터를 연결하는 표준 통신 규약이다.

- **Host:** AI 애플리케이션
- **Client:** MCP 서버와 통신
- **Server:** Tool, Resource, Prompt 제공
- **Tool:** 실행 가능한 함수
- **Resource:** 읽을 수 있는 데이터
- **Prompt:** 재사용 가능한 메시지 템플릿

MCP는 JSON-RPC 2.0을 사용하며 `tools/list`, `tools/call` 등의 작업을 정의한다.

### 실습 내용

1. FastMCP 기반 가상 날씨 서버 실행
2. `MultiServerMCPClient`로 서버 연결
3. MCP Tool 목록 조회 및 직접 호출
4. LangGraph Agent에 MCP Tool 연결
5. Resource 및 Prompt 조회
6. Claude Code에서 동일한 MCP 서버 사용

### 주요 코드

```python
from langchain_mcp_adapters.client import MultiServerMCPClient

client = MultiServerMCPClient({
    "weather": {
        "transport": "streamable_http",
        "url": "http://127.0.0.1:8000/mcp"
    }
})

tools = await client.get_tools()
```

Agent 연동:

```python
from langchain.agents import create_agent

agent = create_agent(
    model=llm,
    tools=tools
)
```

### MCP vs A2A

| MCP | A2A |
|---|---|
| AI 애플리케이션과 도구·데이터 연결 | 독립적인 Agent 간 연결 |
| 외부 기능 호출 및 데이터 활용 | 업무 위임 및 협업 |

## 37. Local LLM with Ollama

[실습 노트북](https://drive.google.com/file/d/1wF27I-qgPgkznDrErN8h121PCc67stSQ/view)

### 핵심 개념

- **Ollama:** 로컬 LLM 다운로드 및 실행
- **Hugging Face:** AI 모델과 데이터셋 공유 플랫폼
- **Quantization:** 모델 가중치 정밀도를 낮춰 메모리 사용량 감소
- **ChatOllama:** LangChain에서 Ollama 모델 연동

### 실습 내용

1. Gemini API 기반 LangChain 체인 구성
2. Ollama 설치 및 로컬 서버 실행
3. Qwen 모델 다운로드
4. `ChatOllama`로 LLM 교체
5. 로컬 모델과 Gemini API 비교

### Ollama 실행

```bash
ollama serve
ollama pull qwen3.5:0.8b
pip install langchain-ollama
```

### LangChain 연동

```python
from langchain_ollama import ChatOllama

local_llm = ChatOllama(
    model="qwen3.5:0.8b",
    reasoning=False
)

chain = prompt | local_llm | parser

result = chain.invoke({
    "role": "Python",
    "question": "for 문을 설명해줘"
})
```

### Local LLM vs Gemini API

| 항목 | Local LLM | Gemini API |
|---|---|---|
| 실행 위치 | 로컬 컴퓨터 | 외부 서버 |
| API 호출 비용 | 없음 | 사용량에 따라 다름 |
| 인터넷 | 다운로드 후 로컬 추론에는 불필요 | 필요 |
| 제약 | PC 메모리 및 연산 성능 | API 사용 한도 |

## Key Takeaways

- **MCP:** 외부 도구와 데이터를 여러 AI 애플리케이션에서 표준 방식으로 재사용할 수 있다.
- **Local LLM:** LangChain 체인 구조를 유지하면서 API 기반 LLM을 Ollama 로컬 모델로 교체할 수 있다.
