# PostgreSQL Checkpointer & SQL Agent

## 1. PostgreSQL Persistence

LangGraph의 상태 및 장기 기억 데이터를 PostgreSQL에 저장하는 방법 학습.

| Component | Description |
|---|---|
| `PostgresSaver` | LangGraph 실행 상태 체크포인트 저장 및 복원 |
| `PostgresStore` | 사용자 정보 등 장기 기억 저장 |
| `thread_id` | 대화 스레드별 실행 상태 구분 |

## 2. SQL Fundamentals

| Category | Commands | Purpose |
|---|---|---|
| DDL | CREATE, ALTER, DROP | 데이터베이스 구조 관리 |
| DML | SELECT, INSERT, UPDATE, DELETE | 데이터 조회 및 변경 |
| DCL | GRANT, REVOKE | 데이터베이스 권한 관리 |

## 3. SQL Agent with Tools

사전에 정의된 SQL Tool을 Agent가 선택하여 실행하는 방식 학습.

- `search_countries`: 국가 검색
- `get_country_cities`: 도시 검색

**Workflow**

```text
User Query → Agent → Tool Selection → PostgreSQL → Result
```

## 4. Text-to-SQL with LangGraph

자연어 질문을 SQL로 변환하고 LangGraph로 실행 흐름 및 오류 재시도를 관리.

**SQLState 관리 항목**
- User question
- Generated SQL
- Execution result
- Error
- Retry count

**Workflow**

```text
User Query
    ↓
SQL Generation
    ↓
SQL Validation
    ↓
SQL Execution
    ↓
Success / Error
    ├─ Success → Return Result
    └─ Error → Retry or Return Error
```

## 5. Database Security

LLM이 생성한 SQL의 실행 위험을 줄이기 위한 접근 제어 방법 학습.

- **DB Permissions**: 계정별 SQL 실행 권한 제한
- **Read-only Transaction**: 데이터 변경 제한
- **SQLGlot**: SQL 파싱 및 허용 정책 검증에 활용

## Key Takeaways

1. **Fixed SQL Tools**: 사전 정의된 SQL Tool을 Agent가 선택해 실행
2. **Text-to-SQL + LangGraph**: SQL 생성, 실행, 오류 처리 및 재시도 흐름 관리
3. **Database Access Control**: SQL 검증과 데이터베이스 권한 제한을 통한 안전성 강화
