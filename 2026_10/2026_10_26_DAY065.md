# FastAPI Backend Study — 2026.10.26

## Overview

SQLAlchemy ORM을 활용한 데이터베이스 CRUD, 트랜잭션 관리, 테이블 관계 설정 및 FastAPI 상품 관리 API 실습.

## 1. SQLAlchemy ORM

Python 객체와 관계형 데이터베이스 테이블을 매핑한다.

```python
class Post(Base):
    __tablename__ = "posts"

    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(String(50))
    content: Mapped[str] = mapped_column(Text)
```

주요 구성:
- `Base`: ORM 모델 공통 기반
- `Mapped`, `mapped_column`: 컬럼 정의
- `ForeignKey`: 테이블 간 참조
- `relationship`: ORM 객체 간 관계

## 2. Database & Session

| Component | Role |
|---|---|
| `create_engine()` | DB 연결 인프라 생성 |
| `sessionmaker()` | Session 생성기 설정 |
| `SessionLocal()` | DB 작업용 Session 생성 |
| `Depends(get_db)` | FastAPI 의존성 주입 |
| `Base.metadata.create_all()` | 미생성 테이블 생성 |

## 3. ORM CRUD

```python
# Create
db.add(post)

# Read
posts = db.scalars(select(Post)).all()
post = db.get(Post, post_id)

# Update
post.title = "New Title"

# Delete
db.delete(post)
```

변경 사항은 트랜잭션 확정 과정을 통해 저장한다.

### Transaction

```python
with db.begin():
    db.add(new_post)
```

- 정상 종료: commit
- 예외 발생: rollback

## 4. Layered Architecture

```text
Client
  ↓
Router
  ↓
Service
  ↓
Repository
  ↓
ORM Model
  ↓
Database
```

| Layer | Responsibility |
|---|---|
| Router | HTTP 요청·응답 |
| Schema | Pydantic 데이터 검증 |
| Service | 비즈니스 로직 및 트랜잭션 |
| Repository | 데이터 접근 및 CRUD |
| Model | DB 테이블·관계 매핑 |

`ConfigDict(from_attributes=True)`를 이용한 ORM 객체 기반 Pydantic 응답 모델 구성도 학습했다.

## 5. Database Relationships

### One-to-Many (1:N)

게시글 1개와 댓글 여러 개의 관계.

```python
# Post
comments = relationship(
    "Comment1N",
    back_populates="post",
    cascade="all"
)

# Comment
post_id = mapped_column(ForeignKey("post_1n.id"))

post = relationship(
    "Post1N",
    back_populates="comments"
)
```

### Many-to-Many (N:M)

게시글과 태그 사이에 중간 연결 테이블을 사용한다.

```text
PostMN ← PostTagMN → TagMN
```

- `UniqueConstraint`: 중복 연결 방지
- `association_proxy`: 중간 연결 객체를 통한 접근
- 기존 태그 재사용 및 신규 태그 생성
- 태그 중복 제거와 연결 관리

```python
new_post.tags.append(tag)
```
