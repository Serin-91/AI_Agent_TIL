# SQL SELECT & JOIN Practice

`dvdrental` 및 `world` 데이터베이스를 활용해 SELECT, 집계 함수, JOIN을 학습했다.

## SELECT

```sql
SELECT title, rental_rate
FROM film
WHERE rental_rate >= 4;
```

주요 문법:

- `WHERE`: 행 필터링
- `ILIKE`: 대소문자 구분 없는 문자열 검색
- `BETWEEN`: 범위 조건
- `IN`: 여러 값 중 하나인지 확인
- `DISTINCT`: 중복 제거
- `ORDER BY`: 정렬
- `LIMIT`: 결과 개수 제한
- `OFFSET`: 앞의 결과 건너뛰기

```sql
SELECT title, length
FROM film
ORDER BY length DESC, title ASC
OFFSET 9
LIMIT 6;
```

## GROUP BY

```sql
SELECT
    rating,
    COUNT(*) AS film_count,
    AVG(length) AS avg_length
FROM film
GROUP BY rating;
```

- `COUNT()`: 개수 계산
- `AVG()`: 평균 계산
- `GROUP BY`: 같은 값끼리 그룹화
- `HAVING`: 그룹화된 결과에 조건 적용

```sql
SELECT
    rating,
    AVG(rental_rate) AS avg_rental_rate
FROM film
GROUP BY rating
HAVING AVG(rental_rate) < 3;
```

## JOIN

JOIN은 여러 테이블의 데이터를 연결해 조회할 때 사용한다.

```sql
SELECT
    ci.name AS city_name,
    co.name AS country_name
FROM city ci
JOIN country co
  ON ci.countrycode = co.code;
```

### INNER JOIN

양쪽 테이블에서 조인 조건이 일치하는 데이터만 조회한다.

```sql
SELECT
    a.first_name,
    a.last_name,
    f.title
FROM actor a
JOIN film_actor fa
  ON a.actor_id = fa.actor_id
JOIN film f
  ON fa.film_id = f.film_id;
```

### LEFT JOIN

왼쪽 테이블의 모든 행을 유지하며, 오른쪽에 연결되는 데이터가 없으면 `NULL`을 반환한다.

```sql
SELECT
    f.film_id,
    f.title,
    i.inventory_id
FROM film f
LEFT JOIN inventory i
  ON f.film_id = i.film_id;
```

## ON vs WHERE

- `ON`: 두 테이블을 연결하는 조건
- `WHERE`: JOIN 이후 결과를 필터링하는 조건

LEFT JOIN에서는 조건 위치에 따라 결과가 달라질 수 있다.

```sql
SELECT
    f.title,
    i.inventory_id
FROM film f
LEFT JOIN inventory i
  ON f.film_id = i.film_id
 AND i.store_id = 1;
```

위 쿼리는 모든 영화를 유지하면서 1번 매장 재고만 연결한다.

## Multi-table JOIN

```sql
SELECT
    c.first_name,
    c.last_name,
    a.address,
    ci.city,
    co.country
FROM customer c
JOIN address a
  ON c.address_id = a.address_id
JOIN city ci
  ON a.city_id = ci.city_id
JOIN country co
  ON ci.country_id = co.country_id;
```

테이블 연결 경로:

```text
customer → address → city → country
actor → film_actor → film
film → film_category → category
```

## JOIN + GROUP BY

```sql
SELECT
    a.first_name,
    a.last_name,
    COUNT(fa.film_id) AS film_count
FROM actor a
JOIN film_actor fa
  ON a.actor_id = fa.actor_id
GROUP BY
    a.actor_id,
    a.first_name,
    a.last_name
HAVING COUNT(fa.film_id) >= 30
ORDER BY film_count DESC;
```

## Query Flow

```text
SELECT
→ FROM
→ JOIN / ON
→ WHERE
→ GROUP BY
→ HAVING
→ ORDER BY
→ LIMIT / OFFSET
```

핵심은 JOIN 시 각 테이블의 PK/FK 연결 관계를 따라가며 데이터의 연결 경로를 파악하는 것이다.
