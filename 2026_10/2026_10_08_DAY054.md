# DAY 054｜Database Table Design & SQL

## 학습 주제

화면 요구사항을 기반으로 ERD를 설계하고, SQL을 이용한 테이블 생성 및 데이터 조회 과정을 학습한다.

## 주요 학습 내용

### 1. ERD 설계

- 화면에 필요한 데이터 분석
- 테이블 및 컬럼 정의
- 기본키(PK)와 외래키(FK) 설정
- 테이블 간 관계 설계

### 2. SQL 작성

- 화면별 데이터 조회 SQL 작성
- 필요에 따라 여러 SQL 사용
- JOIN을 통한 테이블 간 데이터 연결

### 3. 데이터 생성

- ERD 기반 DDL 작성
- AI를 활용한 테이블 생성 SQL 작성
- ERD와 DDL 구조 비교
- 샘플 데이터 입력

### 4. 데이터 조회 검증

- 화면별 SQL 실행
- 조회 데이터 확인
- 화면 요구사항과 조회 결과 비교

## 주요 SQL

| SQL | 목적 |
|---|---|
| `CREATE TABLE` | 테이블 생성 |
| `INSERT INTO` | 데이터 입력 |
| `SELECT` | 데이터 조회 |
| `JOIN` | 테이블 연결 |

## 실습 예시

```sql
-- 테이블 생성
CREATE TABLE users (
    user_id INTEGER PRIMARY KEY,
    name TEXT NOT NULL
);

CREATE TABLE orders (
    order_id INTEGER PRIMARY KEY,
    user_id INTEGER NOT NULL,
    product_name TEXT NOT NULL,
    FOREIGN KEY (user_id) REFERENCES users(user_id)
);

-- 샘플 데이터 입력
INSERT INTO users (user_id, name)
VALUES (1, '홍길동');

INSERT INTO orders (order_id, user_id, product_name)
VALUES (101, 1, '키보드');

-- 데이터 조회
SELECT
    u.name,
    o.order_id,
    o.product_name
FROM users AS u
JOIN orders AS o
    ON u.user_id = o.user_id;
```

> 예시 SQL은 SQLite 기준의 학습용 코드이며 실제 수업 실습 결과와는 별개이다.

## 학습 핵심

**화면 분석 → ERD 설계 → DDL 작성 → 테이블 생성 → 데이터 입력 → SQL 조회 → 결과 검증**

화면 요구사항을 데이터베이스 구조로 변환하고, SQL을 통해 필요한 데이터를 조회하는 전체 과정을 이해하는 것이 목표이다.

**실습 상태:** 실제 화면, ERD 및 SQL 실행 결과 미제공으로 완료 여부 확인 필요.
