# Financial Agent Evaluation

## Golden Set

`mini-project-3`의 실제 기능과 `initial_data.json`을 기준으로 평가용 Golden Set을 구성했다.

Golden Set 생성 과정:

1. 평가할 기능 선택
2. 실제 초기 데이터 확인
3. 사용자 요청 작성
4. 정상 실행 시 기대 결과 정의
5. `golden_set` 리스트에 저장

Golden Set은 크게 `inputs`와 `reference`로 구성된다.

```text
golden_set
├─ inputs
│  └─ Agent에게 전달할 사용자 요청
│
└─ reference
   ├─ answer_criteria
   │  └─ 기대하는 Agent 응답
   ├─ business
   │  └─ 기대하는 실제 데이터 변경
   └─ approval
      └─ interrupt 및 승인·거절 흐름
```

## Approval Flow

금융 작업은 실제 데이터를 변경하므로
Human-in-the-Loop 승인 과정도 평가한다.

정상 승인 케이스:

```text
interrupt 1회 발생
→ 사용자 승인
→ approval = approved
→ request = completed
```

따라서 평가 시 Agent의 자연어 응답뿐 아니라
**실제 데이터 변경 결과와 승인 흐름까지 함께 확인한다.**
