# Docker & Docker Compose — FastAPI Backend

**Date:** 2026-10-30  
**Topic:** Docker, Docker Compose, FastAPI, PostgreSQL, pgvector

## 1. 학습 개요

Docker와 Docker Compose를 활용하여 FastAPI 백엔드와 PostgreSQL 데이터베이스를 컨테이너 환경에서 실행하고 연결하는 방법을 학습했다.

### 주요 학습 내용

- Dockerfile 기반 이미지 빌드
- Docker Image 및 Container 실행 구조
- Docker Compose를 통한 다중 서비스 관리
- Port Mapping 및 Container Network
- Named Volume을 통한 DB 데이터 보존
- FastAPI + PostgreSQL API 실행
- Gemini Embedding + pgvector 기반 유사 문서 검색

## 3. System Architecture

```text
              Docker Compose
                    │
          ┌─────────┴─────────┐
          │                   │
          ▼                   ▼
    backend                 db
    FastAPI          PostgreSQL + pgvector
    Port 8000        Container Port 5432
          │                   │
          └──── db:5432 ──────┘
                              │
                              ▼
                         postgres_data
                         (Named Volume)
```

### Port Mapping

| 서비스 | Host Port | Container Port |
|---|---|---|
| FastAPI | 8000 | 8000 |
| PostgreSQL | 5433 | 5432 |

- 호스트에서 DB 접근: `localhost:5433`
- FastAPI 컨테이너에서 DB 접근: `db:5432`
- Compose 내부 네트워크에서 서비스 이름으로 통신

## 5. Docker Compose Commands

```bash
# 이미지 빌드 및 서비스 실행
docker compose up --build

# 백그라운드 실행
docker compose up -d

# 컨테이너 상태 확인
docker compose ps

# 로그 확인
docker compose logs

# 실시간 로그 확인
docker compose logs -f

# 컨테이너 및 네트워크 정리
docker compose down

# 관련 볼륨까지 제거
docker compose down -v
```

**주의:** `docker compose down`은 기본적으로 이름 있는 볼륨을 보존하지만, `down -v`는 관련 볼륨까지 제거하므로 DB 데이터 삭제에 주의해야 한다.

## 7. Embedding & Vector Search

Gemini Embedding과 PostgreSQL pgvector를 활용하여 텍스트 임베딩 저장 및 유사도 검색 기능을 구현했다.

### Ingestion

```text
6 Text Documents
       ↓
Gemini Embedding
       ↓
Vector Generation
       ↓
PostgreSQL (pgvector)
       ↓
Vector Storage
```

### Retrieval

```text
User Query
     ↓
Query Embedding
     ↓
pgvector Similarity Search
     ↓
Top 2 Relevant Documents
     ↓
Search Results
```

### 구현 범위

- 텍스트 6개 임베딩 및 저장
- 사용자 질문 기반 벡터 유사도 검색
- 관련 문서 2개 반환
- LLM 최종 답변 생성은 미포함

현재 `/search`는 문서 검색 기능이며, 검색 결과를 활용해 LLM 답변까지 생성하는 완성형 RAG 파이프라인은 아니다.

## 8. 핵심 정리

1. **Docker:** 애플리케이션 실행 환경을 컨테이너로 구성
2. **Docker Compose:** FastAPI와 PostgreSQL 서비스 통합 관리
3. **Port Mapping:** 호스트와 컨테이너의 접속 포트 연결
4. **Volume:** 컨테이너와 별도로 DB 데이터 보존
5. **Network:** `backend`와 `db` 서비스 간 통신
6. **pgvector:** PostgreSQL 기반 벡터 저장 및 유사도 검색
