# HTML / Frontend Basics

## Frontend

Frontend는 사용자가 브라우저에서 직접 보고 상호작용하는 웹 애플리케이션 영역이다.

| 기술 | 역할 |
|---|---|
| HTML | 화면의 내용과 구조 |
| CSS | 색상, 크기, 여백, 배치 등 스타일 |
| JavaScript | 클릭, 입력 등 사용자 동작 처리와 화면 변경 |

```text
게시글 목록
├── HTML       : 버튼, 게시글 구조
├── CSS        : 색상, 간격, 배치
└── JavaScript : 버튼 클릭 시 데이터 불러오기
```

## Browser & Server

브라우저는 서버에 웹 페이지나 데이터를 요청하고 서버는 HTML, CSS, JavaScript, 이미지, 데이터 등을 응답한다.

```text
브라우저 ── Request ──→ 서버
브라우저 ←─ Response ── 서버
```

웹에서는 주로 HTTP 또는 HTTPS를 이용한다.

## HTML

HTML(HyperText Markup Language)은 태그를 사용해 웹 문서의 내용과 구조를 표현한다.

```html
<a href="https://www.python.org/">Python 공식 사이트</a>
```

- `<a>` : 링크 태그
- `href` : 이동할 주소를 지정하는 속성
- `Python 공식 사이트` : 화면에 표시되는 내용

## Element & Attribute

HTML 요소는 일반적으로 시작 태그, 내용, 종료 태그로 구성되며 속성을 추가할 수 있다.

```html
<p class="title">HTML 기초</p>
```

- Tag : `<p>`, `</p>`
- Attribute : `class="title"`
- Content : `HTML 기초`

`<img>`, `<input>`, `<br>`처럼 종료 태그가 없는 요소도 있다.

## Basic HTML Structure

```html
<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>게시글 목록</title>
  </head>

  <body>
    <h1>게시글 목록</h1>
    <p>게시글을 확인하세요.</p>
  </body>
</html>
```

- `<!DOCTYPE html>` : 표준 HTML 문서 선언
- `<html>` : 문서 전체의 루트 요소
- `<head>` : 문서 정보
- `<title>` : 브라우저 탭 제목
- `<body>` : 화면에 표시되는 내용

## Common Tags

| 태그 | 역할 |
|---|---|
| `<h1>` ~ `<h6>` | 제목 계층 |
| `<p>` | 단락 |
| `<div>` | 여러 요소를 하나의 영역으로 묶음 |
| `<span>` | 내용의 일부를 묶음 |
| `<ul>` | 순서 없는 목록 |
| `<li>` | 목록 항목 |

## Semantic Tags

| 태그 | 역할 |
|---|---|
| `<header>` | 페이지 또는 영역의 머리말 |
| `<nav>` | 메뉴 및 탐색 링크 |
| `<main>` | 주요 콘텐츠 |
| `<article>` | 독립적인 콘텐츠 |
| `<footer>` | 페이지 또는 영역의 바닥글 |

## Links & Images

```html
<a href="https://www.python.org/about/">Python 소개</a>

<img
  src="https://www.python.org/static/img/python-logo.png"
  alt="Python 로고"
>
```

- `href` : 링크 목적지
- `src` : 불러올 파일 주소
- `alt` : 이미지 대체 텍스트

### Absolute / Relative URL

기준 문서:

```text
https://example.com/docs/page.html
```

```text
/about/
→ https://example.com/about/

about/
→ https://example.com/docs/about/
```

## Form

```html
<form action="https://www.python.org/search/" method="get">
  <label for="search">검색어</label>
  <input
    id="search"
    name="q"
    type="text"
    placeholder="검색어를 입력하세요"
  >
  <button type="submit">검색</button>
</form>
```

- `<form>` : 입력값 전송
- `<input>` : 사용자 입력
- `<label>` : 입력 요소 설명
- `<button>` : 클릭 가능한 버튼
- `name="q"` : 서버로 전달되는 데이터의 키
- `method="get"` : 입력값을 URL에 포함해 전송

`python` 입력 시:

```text
https://www.python.org/search/?q=python
```

## id & class

### id

특정 요소에 고유한 식별자를 지정한다.

```html
<h1 id="page-title">게시글 목록</h1>
```

### class

여러 요소를 같은 그룹으로 묶을 수 있다.

```html
<p class="title">HTML 기초</p>
<p class="title featured">CSS 선택자</p>
```

한 요소에는 여러 클래스를 지정할 수 있으며 공백으로 구분한다.

## Element Relationships

```html
<ul>
  <li class="post">
    <a class="title">HTML 기초</a>
    <div class="details">
      <p class="body">HTML 설명</p>
    </div>
  </li>
</ul>
```

- Parent : 바로 바깥 요소
- Child : 바로 안쪽 요소
- Sibling : 같은 부모를 가진 요소
- Descendant : 내부에 포함된 모든 단계의 요소

## Anchor Link

```html
<a href="#post-1">HTML 기초</a>

<li id="post-1">
  ...
</li>
```

`href="#post-1"`은 같은 문서에서 `id="post-1"`을 가진 요소의 위치로 이동한다.

## HTML Comment

```html
<!-- 게시글 목록 영역 -->
<ul id="post-list"></ul>
```

주석은 일반 화면에는 표시되지 않지만 HTML 소스와 개발자 도구에서는 확인할 수 있다.
