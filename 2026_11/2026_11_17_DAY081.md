## 1. Transfer Learning

사전학습된 모델의 가중치를 새로운 문제에 재사용하는 학습 기법.

### Core Concepts

| Concept | Description |
|---|---|
| Pretrained Model | 기존 데이터로 학습된 모델 |
| Feature Extraction | 기존 가중치 동결 후 분류층 학습 |
| Fine-tuning | 기존 가중치 일부 또는 전체 추가 학습 |
| ResNet18 | 잔차 연결을 활용하는 CNN 모델 |

### Feature Extraction Example

```python
import torch.nn as nn
from torchvision import models

model = models.resnet18(
    weights=models.ResNet18_Weights.DEFAULT
)

for param in model.parameters():
    param.requires_grad_(False)

num_features = model.fc.in_features

model.fc = nn.Linear(num_features, 2)
```

## 2. Autoencoder

입력 데이터를 잠재 표현으로 압축하고 다시 복원하는 신경망.

### Architecture

```text
Input
  ↓
Encoder
  ↓
Latent Vector
  ↓
Decoder
  ↓
Reconstruction
```

### Core Components

| Component | Description |
|---|---|
| Encoder | 입력 특징 추출 및 압축 |
| Latent Vector | 압축된 특징 표현 |
| Decoder | 입력 데이터 복원 |
| MSELoss | 원본과 복원 결과의 오차 계산 |

### PyTorch Example

```python
import torch.nn as nn

class Autoencoder(nn.Module):
    def __init__(self):
        super().__init__()

        self.encoder = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 32)
        )

        self.decoder = nn.Sequential(
            nn.Linear(32, 128),
            nn.ReLU(),
            nn.Linear(128, 784),
            nn.Sigmoid()
        )

    def forward(self, x):
        x = x.view(x.size(0), -1)
        latent = self.encoder(x)
        return self.decoder(latent)
```

## 3. Recurrent Neural Network (RNN)

이전 시점의 정보를 Hidden State로 전달하며 순차 데이터를 처리하는 신경망.

### Core Concepts

- **Sequence Data:** 순서가 중요한 입력 데이터
- **Hidden State:** 이전 시점의 정보 전달
- **One-hot Encoding:** 문자를 벡터로 변환
- **Padding:** 서로 다른 시퀀스 길이 조정

### RNN Architecture

```text
Input Sequence
      ↓
One-hot Encoding
      ↓
Padding / Sequence Processing
      ↓
RNN
      ↓
Hidden State
      ↓
Linear
      ↓
Class Logits
```

### PyTorch Example

```python
import torch.nn as nn

class NameRNN(nn.Module):
    def __init__(self, input_size, hidden_size, num_classes=18):
        super().__init__()

        self.rnn = nn.RNN(
            input_size=input_size,
            hidden_size=hidden_size,
            batch_first=True
        )

        self.fc = nn.Linear(hidden_size, num_classes)

    def forward(self, x):
        output, hidden = self.rnn(x)
        return self.fc(hidden[-1])
```

※ Padding이 포함된 배치는 별도의 길이 처리가 필요할 수 있다.

### Evaluation

| Metric | Purpose |
|---|---|
| Accuracy | 전체 분류 정확도 |
| Macro F1 | 클래스별 F1-score의 단순 평균 |
| Confusion Matrix | 클래스별 예측 오류 분석 |

## 4. Hyperparameter Optimization

검증 성능을 기준으로 모델의 하이퍼파라미터 조합을 탐색하는 과정.

> 주요 실습 모델: Random Forest (Machine Learning)

### Cross Validation

| Method | Description |
|---|---|
| K-Fold | K개 부분으로 데이터를 분할하여 교차검증 |
| StratifiedKFold | 클래스 비율을 유지하며 교차검증 |

### Search Methods

| Method | Strategy |
|---|---|
| GridSearchCV | 모든 지정 조합 탐색 |
| RandomizedSearchCV | 무작위 하이퍼파라미터 조합 탐색 |
| Optuna | 탐색 이력 기반 최적화 지원 |

### GridSearchCV Example

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import GridSearchCV

model = RandomForestClassifier(random_state=42)

param_grid = {
    "n_estimators": [100, 200],
    "max_depth": [5, 10, None]
}

search = GridSearchCV(
    estimator=model,
    param_grid=param_grid,
    cv=5,
    scoring="accuracy"
)

search.fit(X_train, y_train)

print(search.best_params_)
print(search.best_score_)
```

### Optuna Example

```python
import optuna

from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score

def objective(trial):
    model = RandomForestClassifier(
        n_estimators=trial.suggest_int(
            "n_estimators", 50, 200
        ),
        max_depth=trial.suggest_int(
            "max_depth", 3, 15
        ),
        random_state=42
    )

    return cross_val_score(
        model,
        X_train,
        y_train,
        cv=5,
        scoring="accuracy"
    ).mean()

study = optuna.create_study(direction="maximize")
study.optimize(objective, n_trials=20)

print(study.best_params)
```

### Evaluation Metrics

- **Accuracy:** 정답 클래스 예측 비율
- **Log Loss:** 예측 확률의 품질 평가

### Optimization Workflow

```text
Train / Test Split
        ↓
Cross Validation
        ↓
Hyperparameter Search
        ↓
Best Parameters
        ↓
Model Retraining
        ↓
Final Test Evaluation
```
