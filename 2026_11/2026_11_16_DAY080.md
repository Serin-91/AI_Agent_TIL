## 1. Neural Network Architecture

### Core Concepts

| Concept | Description |
|---|---|
| Neuron | 가중합과 활성화 함수를 이용한 계산 단위 |
| Weight | 입력 특성의 영향력을 결정하는 학습 파라미터 |
| Bias | 가중합에 더해지는 학습 파라미터 |
| ReLU | 비선형 활성화 함수 |
| MLP | 다층 완전연결 신경망 |
| Tensor | 다차원 데이터 구조 |
| Forward Propagation | 입력에서 출력까지의 계산 |
| Logits | 확률 변환 전 출력 점수 |
| Softmax | 클래스 점수를 확률 분포로 변환 |

### MLP Example

```python
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self):
        super().__init__()

        self.network = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, 10)
        )

    def forward(self, x):
        x = x.view(x.size(0), -1)
        return self.network(x)
```

**Key Points**
- ReLU adds non-linearity.
- MLP learns patterns through fully connected layers.
- Softmax converts Logits into probabilities.
- `CrossEntropyLoss` accepts raw Logits.

## 2. Neural Network Training

### Dataset & DataLoader

```python
from torch.utils.data import DataLoader

train_loader = DataLoader(
    train_dataset,
    batch_size=32,
    shuffle=True
)
```

### Batch & Epoch

- Batch: 학습 데이터를 나눈 묶음
- Epoch: 전체 학습 데이터를 한 번 순회
- `drop_last=False`: 마지막 불완전 배치 유지

**Example**

```text
Dataset Size: 1,077
Batch Size: 32
drop_last: False

Batches per Epoch: 34
```

### Loss Function

| Loss | Application |
|---|---|
| MSELoss | Regression |
| CrossEntropyLoss | Multi-class Classification |
| BCEWithLogitsLoss | Binary Classification |

### Backpropagation & Optimizer

```python
import torch.optim as optim

criterion = nn.CrossEntropyLoss()

optimizer = optim.Adam(
    model.parameters(),
    lr=0.001
)

optimizer.zero_grad()

logits = model(images)
loss = criterion(logits, labels)

loss.backward()
optimizer.step()
```

### Training Workflow

```text
Input
  ↓
Forward
  ↓
Loss Calculation
  ↓
Backward
  ↓
Optimizer Step
  ↓
Parameter Update
```

### Evaluation

```python
model.eval()

with torch.no_grad():
    logits = model(images)
    predictions = logits.argmax(dim=1)
```

- `model.train()`: Training Mode
- `model.eval()`: Evaluation Mode
- `torch.no_grad()`: Disable Gradient Tracking

## 3. Convolutional Neural Network (CNN)

### Core Components

| Component | Description |
|---|---|
| Convolution | 지역적 특징 추출 |
| Filter / Kernel | 학습 가능한 특징 추출 가중치 |
| Feature Map | 합성곱 연산의 출력 |
| ReLU | 비선형 활성화 |
| Pooling | 공간 크기 축소 |
| Flatten | 특징 맵을 벡터로 변환 |
| Linear | 최종 클래스 점수 계산 |

### CNN Architecture

```text
Input Image
    ↓
Conv2d
    ↓
ReLU
    ↓
MaxPool2d
    ↓
Conv2d
    ↓
ReLU
    ↓
MaxPool2d
    ↓
Flatten
    ↓
Linear
    ↓
Logits
```

### PyTorch CNN Example

```python
import torch.nn as nn

class CNN(nn.Module):
    def __init__(self):
        super().__init__()

        self.features = nn.Sequential(
            nn.Conv2d(1, 16, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),

            nn.Conv2d(16, 32, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2)
        )

        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(32 * 7 * 7, 128),
            nn.ReLU(),
            nn.Linear(128, 10)
        )

    def forward(self, x):
        x = self.features(x)
        return self.classifier(x)
```

### Tensor Shape

| Layer | Shape |
|---|---|
| Input | `[B, 1, 28, 28]` |
| Conv1 | `[B, 16, 28, 28]` |
| Pool1 | `[B, 16, 14, 14]` |
| Conv2 | `[B, 32, 14, 14]` |
| Pool2 | `[B, 32, 7, 7]` |
| Flatten | `[B, 1568]` |
| Output | `[B, 10]` |
