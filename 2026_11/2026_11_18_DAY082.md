## 16. Hyperparameter Optimization

모델의 하이퍼파라미터 조합을 비교하여 검증 성능이 좋은 설정을 탐색한다.

### Core Concepts

| Method | Description |
|---|---|
| K-Fold | K개 데이터 분할을 통한 반복 검증 |
| StratifiedKFold | 클래스 비율을 고려한 교차검증 |
| GridSearchCV | 지정된 모든 조합 탐색 |
| RandomizedSearchCV | 무작위 조합 탐색 |
| Optuna | 탐색 이력 기반 최적화 지원 |

### Practice

- Dataset: Handwritten Digits
- Models: Random Forest, Gradient Boosting
- Parameters: `n_estimators`, `max_depth`, `learning_rate`

### GridSearchCV Example

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import GridSearchCV

model = RandomForestClassifier(random_state=42)

param_grid = {
    "n_estimators": [100, 200],
    "max_depth": [5, 10, None]
}

search = GridSearchCV(
    estimator=model,
    param_grid=param_grid,
    cv=5,
    scoring="accuracy"
)

search.fit(X_train, y_train)

print(search.best_params_)
print(search.best_score_)
```

**Key Point:** 하이퍼파라미터는 교차검증으로 선택하며 테스트 데이터는 최종 평가에만 사용한다.

## 17. Credit Risk Prediction & XAI

신용 계약의 불량 여부를 예측하고 모델의 판단 근거를 분석한다.

### Practice

- Dataset: 1,000 Credit Contracts
- Models: Logistic Regression, Random Forest
- Objective: Credit Risk Classification & Model Interpretation

### Classification Metrics

| Metric | Description |
|---|---|
| Precision | 양성 예측 중 실제 양성의 비율 |
| Recall | 실제 양성 중 탐지 성공 비율 |
| ROC AUC | 여러 임계값에서의 분류 구분 성능 |
| PR Curve | Precision과 Recall의 관계 |

### SHAP

SHAP은 입력 특성이 모델 출력에 기여하는 정도를 분석한다.

- Global Interpretation: 전체 데이터의 특성 기여도 분석
- Local Interpretation: 개별 예측의 특성 기여도 분석

### Threshold Optimization

```text
Prediction Scores
       ↓
Threshold Candidates
       ↓
Precision / Recall Evaluation
       ↓
Recall ≥ 80% Target
       ↓
Threshold Selection
       ↓
Final Test Evaluation
```

**Key Point:** 예측 정확도뿐 아니라 예측의 근거와 Threshold에 따른 판단 변화를 분석한다.

## 18. Fraud Detection

극단적인 클래스 불균형이 존재하는 카드 거래 데이터에서 이상거래를 탐지한다.

### Dataset

| Category | Count |
|---|---:|
| Total Transactions | 284,807 |
| Fraud Transactions | 492 |
| Normal Transactions | 284,315 |
| Fraud Ratio | ~0.17% |

### Data Preprocessing

- EDA
- Missing Value Analysis
- Duplicate Detection
- Class Distribution Analysis
- Amount Transformation using `log1p`

```python
import numpy as np

df["Amount_log"] = np.log1p(df["Amount"])
```

### Isolation Forest

무작위 분할을 통해 쉽게 고립되는 데이터를 이상치로 판단한다.

```python
from sklearn.ensemble import IsolationForest

model = IsolationForest(
    contamination=0.01,
    random_state=42
)

model.fit(X_train)

predictions = model.predict(X_test)
scores = model.decision_function(X_test)
```

- `predict()`: 정상 1, 이상치 -1
- 낮은 Decision Score: 이상치일 가능성이 높음

### Autoencoder

정상 거래의 특징을 학습하고 복원 오차를 이용하여 이상거래 후보를 탐지한다.

```text
Normal Transactions
        ↓
     Encoder
        ↓
   Latent Vector
        ↓
     Decoder
        ↓
  Reconstruction
        ↓
Reconstruction Error
        ↓
Anomaly Detection
```

### Reconstruction Error

```python
import torch

model.eval()

with torch.no_grad():
    reconstructed = model(X_test_tensor)

    errors = (
        (X_test_tensor - reconstructed) ** 2
    ).mean(dim=1)
```

### Evaluation Metrics

| Metric | Purpose |
|---|---|
| Precision | 사기 판정의 정확성 |
| Recall | 실제 사기 탐지 비율 |
| F1 Score | Precision과 Recall의 균형 |
| Average Precision | 여러 임계값에서의 PR 성능 |
| FP | 정상 거래 오탐 |
| FN | 사기 거래 미탐 |

### Model Selection Workflow

```text
Transaction Data
       ↓
EDA & Preprocessing
       ↓
Train / Validation / Test Split
       ↓
 ┌───────────────┐
 │               │
Isolation      Autoencoder
Forest
 │               │
Anomaly Score   Reconstruction Error
 │               │
 └───────┬───────┘
         ↓
Validation Metrics
         ↓
Model & Threshold Selection
         ↓
Final Test Evaluation
```

**Key Point:** 극단적인 클래스 불균형에서는 Accuracy 외에 Recall, Precision, F1, AP, FP, FN을 함께 평가한다.
