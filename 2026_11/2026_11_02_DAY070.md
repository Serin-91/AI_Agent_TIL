# AI Search Service — AWS & Vercel Deployment

**Topic:** AWS EC2, RDS PostgreSQL, Docker Compose, Nginx, HTTPS, Vercel

## 1. 학습 개요

로컬 환경에서 개발한 FastAPI 기반 AI 문서 검색 서비스를 AWS와 Vercel에 배포하고, 프론트엔드·백엔드·데이터베이스를 연결했다.

### 주요 학습 내용

- AWS EC2 백엔드 배포
- AWS RDS PostgreSQL 및 pgvector 연결
- Docker Compose 기반 FastAPI·Nginx 실행
- Nginx 리버스 프록시 구성
- Let's Encrypt HTTPS 인증서 발급 및 자동 갱신 예약
- Vercel React 프론트엔드 배포
- CORS 및 API 환경변수 설정
- 배포 환경에서 서버·DB 연결 및 문서 검색 검증

| Component | Platform | Responsibility |
|---|---|---|
| Frontend | Vercel | React 웹 애플리케이션 |
| Backend | AWS EC2 | FastAPI API 서버 |
| Database | AWS RDS | PostgreSQL 데이터 관리 |
| Vector Search | pgvector | 임베딩 유사도 검색 |
| Container | Docker Compose | FastAPI·Nginx 관리 |
| Reverse Proxy | Nginx | HTTPS 요청 전달 |
| TLS Certificate | Let's Encrypt | HTTPS 인증서 |

   │
   ▼

   │

   │     └── Reverse Proxy / HTTPS
   │
   └── FastAPI
         └── REST API / Vector Search
                    │

- 환경변수로 DB 접속 설정 관리

## 4. Nginx & HTTPS

Nginx를 리버스 프록시로 구성하여 외부 요청을 FastAPI에 전달한다.

| Protocol | Default Port | Description |
|---|---|---|
| HTTP | 80 | 일반 HTTP |
| HTTPS | 443 | TLS 암호화 통신 |

### HTTPS Configuration

- Let's Encrypt 인증서 발급
- Nginx HTTPS 설정
- 인증서 자동 갱신 예약

```text
Client
   │
   │ HTTPS :443
   ▼
Nginx
   │
   ▼
FastAPI
```

## 6. CORS Configuration

서로 다른 Origin에서 동작하는 Vercel 프론트엔드와 FastAPI 백엔드의 통신을 위해 CORS를 설정했다.

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "https://my-app.vercel.app"
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

※ 예시 설정이며 실제 배포 Origin에 맞게 변경해야 한다.

7. **CORS:** 브라우저의 교차 출처 API 접근 허용
