## 1. Logistic Regression

- **Logistic Regression**: 확률 기반 분류 모델
- **Sigmoid**: 입력값을 0~1 사이로 변환
- **Binary Classification**: 두 개의 클래스 분류
- **Confusion Matrix**: TP, TN, FP, FN 기반 성능 분석

### Classification Metrics

| Metric | Description |
|---|---|
| Precision | TP / (TP + FP) |
| Recall | TP / (TP + FN) |
| F1-score | Precision과 Recall의 조화평균 |

```python
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import precision_score, recall_score, f1_score

model = LogisticRegression(max_iter=1000)
model.fit(X_train, y_train)

predictions = model.predict(X_test)

print(precision_score(y_test, predictions))
print(recall_score(y_test, predictions))
print(f1_score(y_test, predictions))
```

## 2. Tree Ensemble

여러 결정 트리의 예측을 결합하여 모델 성능을 개선하는 기법.

| Model | 핵심 특징 |
|---|---|
| Random Forest | Bagging 기반 앙상블 |
| Gradient Boosting | 순차적으로 오류를 보완하는 Boosting |

**주요 하이퍼파라미터**
- `n_estimators`: 트리 또는 부스팅 단계 수
- `max_depth`: 트리 최대 깊이
- `learning_rate`: Boosting 단계별 기여도

모델 성능은 동일한 데이터 분리와 평가 지표를 기준으로 비교한다.

## 3. K-means Clustering

정답이 없는 데이터를 K개의 군집으로 구분하는 비지도학습 알고리즘.

**동작 과정**

1. 군집 개수 K 설정
2. 초기 중심점 선택
3. 가까운 중심점에 데이터 할당
4. 군집별 중심점 갱신
5. 수렴할 때까지 반복

**군집 수 평가**
- Elbow Method: Inertia 감소 추세 분석
- Silhouette Score: 군집 응집도 및 분리도 평가

```python
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

model = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)

labels = model.fit_predict(X_scaled)

score = silhouette_score(X_scaled, labels)
```

## 4. PCA (Principal Component Analysis)

데이터 분산을 최대한 보존하는 새로운 축을 찾아 차원을 축소하는 기법.

**핵심 개념**
- Principal Component: 데이터 분산을 설명하는 새로운 축
- Explained Variance Ratio: 각 주성분의 분산 설명 비율
- Cumulative Explained Variance: 선택한 주성분의 누적 설명 비율

```python
from sklearn.decomposition import PCA

pca = PCA(n_components=0.9)

X_pca = pca.fit_transform(X_scaled)

print(pca.explained_variance_ratio_)
print(pca.explained_variance_ratio_.cumsum())
```

`n_components=0.9`는 지원되는 solver에서 누적 설명분산비율 90% 이상을 유지하도록 주성분 수를 선택한다.
