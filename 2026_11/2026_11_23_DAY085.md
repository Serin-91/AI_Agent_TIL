## 19. Transformer Architecture

Transformer 기반 언어 모델의 입력 처리, Attention 및 Autoregressive 생성 구조 학습.

### Core Components

| Component | Description |
|---|---|
| Tokenizer | 텍스트를 토큰 ID로 변환 |
| Embedding | 토큰 ID를 벡터로 변환 |
| Attention | 토큰 간 관련성 계산 |
| Q/K/V | Query, Key, Value |
| Multi-Head Attention | 여러 Attention Head의 정보 결합 |
| Causal Mask | 미래 토큰 참조 차단 |
| FFN | 토큰별 특징 변환 |
| LM Head | 다음 토큰 Logits 계산 |
| Autoregressive | 다음 토큰 반복 생성 |
| KV Cache | 기존 Key/Value 재사용 |

### Transformer Workflow

```text
Input Text
    ↓
Tokenizer
    ↓
Token IDs
    ↓
Embedding
    ↓
Transformer Blocks
 ├─ Attention
 └─ FFN
    ↓
LM Head
    ↓
Next-token Logits
    ↓
Token Generation
```

### Scaled Dot-Product Attention

\[
Attention(Q,K,V)=Softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V
\]

### Key Points

- Q/K: 토큰 관련성 계산
- V: 전달할 정보
- Causal Mask: 미래 토큰 참조 방지
- KV Cache: 반복적인 Key/Value 계산 감소
- Autoregressive: 이전 토큰을 바탕으로 다음 토큰 생성

## 20. Fine-tuning & LoRA

사전학습 언어 모델을 특정 작업에 맞게 효율적으로 추가 학습하는 기법.

### Core Concepts

| Concept | Description |
|---|---|
| Fine-tuning | 사전학습 모델 추가 학습 |
| SFT | 질문·모범 답변 기반 지도 파인튜닝 |
| LoRA | 저랭크 어댑터만 학습 |
| Rank | LoRA 중간 차원 |
| Alpha | LoRA 출력 스케일 관련 설정 |
| Quantization | 가중치 표현 비트 수 감소 |
| QLoRA | 양자화된 기본 모델 + LoRA |
| RAG | 외부 정보 검색을 통한 응답 생성 보강 |

### LoRA Architecture

```text
Pretrained LLM
      ↓
Freeze Base Weights
      ↓
Attach LoRA Adapters
      ↓
Train Adapter Parameters
      ↓
Save Adapter Weights
```

### LoRA Weight Update

\[
W'=W+\frac{\alpha}{r}BA
\]

- `W`: 기존 가중치
- `A`, `B`: 학습 가능한 저랭크 행렬
- `r`: Rank
- `α`: Alpha

### Fine-tuning vs RAG

| Fine-tuning | RAG |
|---|---|
| 모델 파라미터 조정 | 외부 정보 검색 |
| 모델 행동 및 작업 적응 | 관련 정보 제공 |
| 학습 데이터 필요 | 검색할 지식 데이터 필요 |
| 학습된 가중치 활용 | 검색 결과를 입력에 활용 |

## 21. LoRA Fine-tuning Practice

Qwen2.5-1.5B-Instruct 모델을 KoAlpaca 한국어 질문·응답 데이터로 LoRA 파인튜닝하는 실습.

### Experiment Configuration

| Item | Configuration |
|---|---|
| Base Model | Qwen2.5-1.5B-Instruct |
| Dataset | KoAlpaca |
| Training Samples | 512 |
| Validation Samples | 64 |
| Fine-tuning | LoRA |
| Library | PEFT, Transformers |
| Target Modules | `q_proj`, `v_proj` |
| Trainer | Hugging Face Trainer |

### Model Loading

```python
from transformers import (
    AutoTokenizer,
    AutoModelForCausalLM
)

model_id = "Qwen/Qwen2.5-1.5B-Instruct"

tokenizer = AutoTokenizer.from_pretrained(
    model_id
)

model = AutoModelForCausalLM.from_pretrained(
    model_id
)
```

### LoRA Configuration

```python
from peft import LoraConfig, get_peft_model

lora_config = LoraConfig(
    r=8,
    lora_alpha=16,
    target_modules=["q_proj", "v_proj"],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)

model = get_peft_model(
    model,
    lora_config
)
```

> LoRA 하이퍼파라미터 값은 구조 설명을 위한 예시이며, 실제 실습 설정값과 다를 수 있다.

### Response-only Loss

```text
Input Tokens:
[Prompt Tokens][Response Tokens]

Labels:
[-100 ... -100][Response Labels]
```

- 질문 영역은 Loss 계산에서 제외
- 정답 응답 토큰을 기준으로 학습
- Causal Language Modeling 방식 활용

### Training Workflow

```text
Qwen2.5 Base Model
         ↓
KoAlpaca Dataset
         ↓
Train / Validation Split
         ↓
Tokenization
         ↓
Response Loss Masking
         ↓
PEFT LoRA Configuration
         ↓
Trainer Training
         ↓
Evaluation
         ↓
Before / After Comparison
         ↓
Adapter Save & Reload
```

### Trainer

```python
from transformers import TrainingArguments

training_args = TrainingArguments(
    output_dir="./lora-output",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    learning_rate=2e-4,
    eval_strategy="epoch",
    save_strategy="epoch",
    report_to="none"
)
```

> 학습 설정은 예시이며 실제 실행 환경과 데이터 전처리 방식에 맞게 조정해야 한다.

### Save LoRA Adapter

```python
model.save_pretrained("./qwen-lora-adapter")
```

### Load LoRA Adapter

```python
from peft import PeftModel
from transformers import AutoModelForCausalLM

base_model = AutoModelForCausalLM.from_pretrained(
    "Qwen/Qwen2.5-1.5B-Instruct"
)

model = PeftModel.from_pretrained(
    base_model,
    "./qwen-lora-adapter"
)
```

### Evaluation

- Training / Validation Loss
- Before / After Response Comparison
- Korean Response Quality
- Instruction Following
- Adapter Reusability

## Key Takeaways

1. **Transformer:** Attention 기반 문맥 처리 및 토큰 생성
2. **Q/K/V:** Attention의 관련성 계산과 정보 전달
3. **Causal Mask:** 미래 토큰 참조 방지
4. **KV Cache:** Autoregressive 생성 효율 개선
5. **SFT:** 질문·정답 기반 지도 파인튜닝
6. **LoRA:** 기본 가중치 동결 후 저랭크 어댑터 학습
7. **QLoRA:** 양자화와 LoRA 결합
8. **RAG:** 외부 지식 검색 기반 응답 보강
9. **PEFT:** 파라미터 효율적 학습 지원
10. **Trainer:** 학습·평가 관리
11. **Adapter:** 학습 결과 저장·복원·재사용
