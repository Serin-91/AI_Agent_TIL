## 1. AI · ML · DL · LLM

- **AI**: 인공지능 기술 전반
- **ML**: 데이터 기반 패턴 학습
- **DL**: 다층 인공신경망 기반 머신러닝
- **LLM**: 대규모 언어 모델
- **Supervised Learning**: 레이블을 이용한 분류·회귀
- **Unsupervised Learning**: 군집화·차원 축소 등 패턴 탐색

## 2. Pandas · NumPy

| Library | 주요 역할 |
|---|---|
| Pandas | 데이터 탐색·가공·분석 |
| NumPy | 배열·행렬 및 수치 연산 |

**주요 API**
- Pandas: `DataFrame`, `head()`, `info()`, `describe()`
- NumPy: `array()`, `reshape()`, `mean()`, `sum()`

## 3. Machine Learning Basics

- `fit()`: 모델 학습
- `predict()`: 예측
- `DecisionTree`: 조건 기반 데이터 분할
- `Overfitting`: 학습 데이터에 과도하게 적합되는 현상

과적합 완화 방법:
- 모델 복잡도 제한
- 적절한 데이터 검증
- 규제 적용

## 4. Data Preprocessing

- **Missing Values**: 결측값 제거 및 대체
- **Scaling**: StandardScaler, MinMaxScaler
- **Encoding**: One-Hot Encoding
- **Data Split**: train_test_split
- **Pipeline**: 전처리 및 모델 학습 단계 연결

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge

pipeline = Pipeline([
    ("scaler", StandardScaler()),
    ("model", Ridge(alpha=1.0))
])

pipeline.fit(X_train, y_train)
predictions = pipeline.predict(X_test)
```

전처리 기준은 학습 데이터에서 학습하여 데이터 누수를 방지한다.

## 5. Regression

| Model | 특징 |
|---|---|
| Linear Regression | 선형 관계 학습 |
| Ridge | L2 규제로 계수 축소 |
| Lasso | L1 규제로 변수 선택 가능 |

### Regression Metrics

| Metric | Description |
|---|---|
| MAE | Mean Absolute Error |
| MSE | Mean Squared Error |
| RMSE | Root Mean Squared Error |
| R² | Coefficient of Determination |

```python
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
import numpy as np

mae = mean_absolute_error(y_test, predictions)
mse = mean_squared_error(y_test, predictions)
rmse = np.sqrt(mse)
r2 = r2_score(y_test, predictions)
```
