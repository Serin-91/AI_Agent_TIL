# RAG Agent / Router / Guardrails / Reflection + Evaluator-Optimizer

## RAG Agent

기존 RAG의 Retriever를 Tool로 변환하여 Agent가 필요할 때만 문서 검색을 수행하는 구조를 학습했다.

```text
사용자 질문
   ↓
Agent 판단
   ├─ 검색 필요 → Retriever Tool → 문서 검색 → 답변
   └─ 검색 불필요 → 바로 답변
```

* `create_retriever_tool()`: Retriever를 Agent가 사용할 Tool로 변환
* `create_agent()`: Retriever Tool을 사용할 수 있는 Agent 생성
* `MemorySaver()` + 동일한 `thread_id`: 이전 대화를 이어서 처리

실습 흐름:

```text
SPRi AI Brief PDF
→ Chroma
→ Retriever
→ Retriever Tool
→ RAG Agent
→ Memory
```

## Router

사용자 요청을 보고 적절한 처리 경로를 선택하는 구조다.

* Deterministic Routing: 키워드나 규칙 기반 분류
* LLM Routing: LLM + Structured Output 기반 분류
* Hybrid Routing: 명확한 요청은 규칙으로 처리하고, 애매한 요청만 LLM 사용
* Semantic Routing: 임베딩 유사도 기반 분류
* Fallback: 확신이 낮은 경우 별도 처리
* Flat / Hierarchical Routing: 경로 수에 따라 단일 또는 계층형 분류

```text
사용자 요청
   ↓
Router
   ├─ 환불 문의 → refund
   ├─ 배송 문의 → shipping
   ├─ 일반 문의 → general
   └─ 애매함 → fallback / LLM 판단
```

주요 평가 지표:

* `routing accuracy`: 올바른 목적지를 선택한 비율
* `fallback rate`: 자동 분류하지 않고 보류한 비율
* `unsafe routing rate`: 위험한 잘못된 경로를 선택한 비율
* `latency`: 최종 처리까지 걸린 시간
* `token cost`: Router와 처리 Node가 사용한 전체 토큰

## Guardrails

Agent가 허용된 범위 안에서 동작하도록 입력과 출력을 검사하는 안전 통제 장치다.

### Input Guardrail

```text
START
  ↓
입력 검사
  ├─ 정상 → 실제 처리 → END
  └─ 위험 → 거부 응답 → END
```

Agent가 요청을 처리하기 전에 사용자 입력을 검사한다.

### Output Guardrail

```text
LLM 답변 생성
    ↓
출력 검사
    ├─ 안전 → 그대로 전달
    └─ 문제 발견 → 가림 또는 재생성
```

생성된 답변에 개인정보나 API Key 등이 포함되어 있는지 검사한 뒤 사용자에게 전달한다.

## Reflection / Evaluator-Optimizer

Agent가 결과를 한 번 생성하고 끝내는 것이 아니라, 검토와 수정을 반복하는 구조다.

### Reflection

```text
초안 생성
→ 자연어 피드백
→ 수정
```

결과를 다시 보고 부족한 부분을 자연어로 피드백한 뒤 수정한다.

### Evaluator-Optimizer

```text
초안 생성
→ Rubric 기준 평가
→ 합격 시 종료
→ 불합격 시 수정 후 재평가
```

* Reflection: 자연어 중심의 검토
* Evaluator-Optimizer: 정해진 평가 기준을 이용한 검토
* Rubric: 결과의 합격 여부를 판단하는 평가 기준표

## 핵심 정리

```text
RAG Agent
→ 필요할 때 검색 Tool 사용

Router
→ 요청에 맞는 처리 경로 선택

Guardrails
→ 입력과 출력 검사

Reflection / Evaluator-Optimizer
→ 결과를 검토하고 수정
```

단순히 `사용자 → LLM → 답변`으로 끝나는 것이 아니라, Tool 선택, 경로 분기, 안전 검사, 결과 평가와 수정까지 포함하는 Agent 구조를 학습했다.
