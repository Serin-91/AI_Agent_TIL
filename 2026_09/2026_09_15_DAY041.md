# Human-in-the-Loop

Human-in-the-Loop(HITL)은 AI Agent가 모든 작업을 자동으로 처리하지 않고, **중요한 판단이 필요한 시점에서 사람의 확인을 받은 뒤 실행을 이어가는 방식**이다.

## Flow

```text
User Request
    ↓
Agent
    ↓
Action 준비
    ↓
interrupt()
    ↓
Human Review
    ↓
approve / reject
    ↓
Command(resume=...)
    ↓
Resume Agent
    ↓
Complete / Cancel
```

## Core Components

- **State**
  - Agent가 중단되기 전까지의 현재 작업 상태를 저장한다.

- **`interrupt()`**
  - 사람의 판단이 필요한 지점에서 Agent 실행을 중단한다.
  - payload를 통해 필요한 정보를 사람에게 전달한다.

- **Resume Value**
  - 사람이 내린 승인·거절 등의 판단값이다.

- **`Command(resume=...)`**
  - 사람의 판단값을 전달해 중단된 실행을 다시 시작한다.

- **`MemorySaver`**
  - interrupt 시점의 State를 저장한다.

- **`thread_id`**
  - 저장된 실행 상태를 구분한다.
  - 동일한 `thread_id`를 사용해 이전에 중단된 실행을 이어갈 수 있다.

## Example

```text
"홍길동에게 5만원 보내줘"
        ↓
send_payment
        ↓
interrupt()
        ↓
"결제할까요?"
        ↓
approve / reject
        ↓
Command(resume=decision)
        ↓
결제 완료 / 결제 취소
```

## Key Point

```text
interrupt()
Agent → Human

Command(resume=...)
Human → Agent
```

Human-in-the-Loop의 핵심은 **Agent의 실행 흐름 안에 사람의 판단 단계를 포함하고, 중단된 State를 저장한 뒤 같은 실행을 다시 이어가는 것**이다.
