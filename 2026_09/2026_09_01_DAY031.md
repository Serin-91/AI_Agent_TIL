# LangChain Basics

## Prompt Techniques

### Structured Tags

XML 형태의 태그를 이용하여 프롬프트의 입력 데이터와 명령을 구조적으로 구분할 수 있다.

```text
<document>
Document content
</document>

<instruction>
Summarize the document.
</instruction>
```

### Prompt Chaining

복잡한 작업을 여러 단계로 나누어 순차적으로 처리한다.

```text
Document Analysis
→ Key Point Extraction
→ Summary
→ Translation
```

앞 단계의 출력 결과를 다음 단계의 입력으로 전달한다.

## LangChain

LangChain에서는 Prompt, LLM, Python 함수, Parser 등의 구성 요소를 연결하여 실행 흐름을 만들 수 있다.

### Runnable

LangChain 구성 요소를 연결하고 실행하기 위한 공통 인터페이스.

### RunnableLambda

사용자 정의 Python 함수를 이용해 입력값을 가공한다.

### RunnablePassthrough

입력값을 변경하지 않고 다음 단계로 전달한다.

### RunnablePassthrough.assign()

기존 입력을 유지하면서 새로운 key 또는 데이터를 추가한다.

---

## LCEL

LCEL(LangChain Expression Language)을 이용해 Runnable들을 `|` 연산자로 연결할 수 있다.

```python
chain = prompt | llm | parser
```

### invoke()

생성한 Chain 또는 Runnable을 한 번 실행한다.

```python
chain.invoke(...)
```

---

## Runnable Execution

### batch()

동일한 Chain에 여러 입력을 전달하여 실행한다.

각 입력마다 별도의 모델 호출이 발생하며 `max_concurrency`를 이용해 동시 실행 요청 수를 제한할 수 있다.

### abatch()

여러 입력을 async 방식으로 처리한다.

### Streaming

생성되는 응답을 chunk 단위로 순차적으로 전달하여 긴 응답을 즉시 출력할 수 있다.

---

## LLM Operations

### Token Usage

`usage_metadata`를 이용하여 토큰 사용량을 확인할 수 있다.

### Fallback

기본 LLM 호출에 실패했을 경우 다른 모델을 호출하도록 구성할 수 있다.

### Cache

`InMemoryCache`를 설정하면 동일한 입력에 대해 캐시된 응답을 재사용할 수 있다.

---

## Few-shot Prompting

원하는 출력 형태의 예시를 프롬프트에 미리 제공하여 모델의 응답 형식을 유도한다.

```text
Example Input
→ Example Output
```

`few-shot`은 프롬프트에 예시를 제공하는 기법이고, `batch()`는 같은 Chain에 여러 입력을 전달하는 실행 방식이다.
