# LangGraph Agent Evaluation

LangGraph Agent의 실행 결과와 행동 과정을 LangSmith를 이용해 평가하는 흐름을 학습했다.

## Core Concepts

- **Agent**: 평가 대상
- **Golden Set**: 문제와 기대 결과를 정의한 평가 기준
- **Dataset**: 평가 문제 모음
- **Evaluator**: 기대 결과와 실제 결과를 비교하는 채점 로직
- **Experiment**: Dataset 전체 평가 결과
- **Trace**: Agent의 실행 과정 기록

## Answer vs Trajectory Evaluation

### Answer Evaluation

최종 답변이 기대한 결과와 일치하는지 평가한다.

```text
answer_correct
→ 최종 답변이 올바른가?
```

### Trajectory Evaluation

Agent가 답변을 생성하기까지 실제로 어떤 행동을 했는지 평가한다.

```text
trajectory_superset_match
→ 필요한 Tool과 핵심 인자를 올바르게 사용했는가?

trajectory_subset_match
→ 허용되지 않은 Tool을 실행하지 않았는가?

approval_flow
→ interrupt → 승인/거절 흐름을 올바르게 처리했는가?
```

## Evaluation Flow

```text
Golden Set
   ↓
Dataset
   ↓
Target / Agent Execution
   ↓
Outputs
   ↓
Evaluator
   ↓
Experiment
   ↓
Trace
   ↓
Fix
   ↓
Re-evaluation
```

### Golden Set

평가에 사용할 문제와 기대 결과를 정의한다.

```text
account_lookup
transfer_approve
transfer_reject
card_lost_approve
```

### Dataset

Golden Set을 LangSmith Dataset으로 저장한다.

```text
financial-agent-eval-...
```

### Target

평가 대상 Agent를 실제 실행한다.

```text
run_agent(inputs)
evaluation_target(inputs)
```

### Outputs

Agent 실행 결과를 평가에 사용한다.

```text
answer
raw_result
business_snapshot
approval
```

### Evaluators

```text
answer_correct
→ 최종 답변 검증

business_result_correct
→ 실제 계좌/카드/request 상태 검증

approval_flow
→ 승인/거절 실행 흐름 검증
```

### Experiment

Dataset 전체를 평가한다.

```python
client.evaluate(...)
```

평가 결과는 LangSmith Experiment에서 확인한다.

### Trace & Re-evaluation

평가 실패 시 Trace를 통해 Node 이동, interrupt 위치, 상태값 등을 확인하고
`graph.py`, prompt, 분류 로직, 승인 흐름 등을 수정한다.

수정 후 동일한 Dataset으로 다시 평가하여
수정 전후 Experiment를 비교한다.

## Summary

**Agent Evaluation은 최종 답변뿐 아니라 Agent의 실제 실행 과정까지 함께 평가하는 과정이다.**

```text
Answer Evaluation
= 제대로 말했는가?

Trajectory Evaluation
= 제대로 행동했는가?
```
