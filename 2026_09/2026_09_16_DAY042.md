# Time Travel & Agentic RAG

## Time Travel

LangGraph의 Checkpointer에 저장된 과거 State를 조회하고, 특정 시점부터 다시 실행하거나 State를 수정하여 새로운 실행 경로를 만드는 기능이다.

- **Checkpoint**: 저장된 실행 시점
- **Replay**: 특정 checkpoint를 기준으로 다시 실행
- **Fork**: 과거 State를 수정하여 다른 실행 경로 생성

```text
Checkpoint
   ├─ Replay → 다시 실행
   └─ Fork   → State 수정 → 새로운 실행 경로
```

## Agentic RAG

검색 결과를 평가하고, 근거가 부족하면 질문을 수정해 다시 검색하는 RAG 구조이다.

```text
START
  ↓
generate_query_or_respond
  ↓
검색 필요?
 ├─ NO → END
 └─ YES
       ↓
    retrieve
       ↓
 grade_documents
    ↙       ↘
근거 있음   근거 없음
   ↓           ↓
답변 생성   rewrite_question
   ↓           ↓
  END        재검색
                ↓
          최대 횟수 반복
                ↓
             abstain
                ↓
               END
```

핵심 흐름:

1. 검색 필요 여부 판단
2. 문서 검색
3. 검색 결과의 관련성 평가
4. 근거가 충분하면 답변 생성
5. 부족하면 질문을 수정하여 재검색
6. 반복 후에도 근거가 없으면 답변을 보류(abstain)

Agentic RAG는 단순 검색에서 끝나지 않고, **검색 결과를 평가하고 다음 행동을 결정한다는 점**이 핵심이다.
