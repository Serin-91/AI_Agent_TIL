# LangChain & RAG Basics

## LangChain

### Output Parser

LLM의 텍스트 출력을 Python에서 사용할 수 있는 구조화된 형태로 변환한다.

### PydanticOutputParser

LLM이 생성한 JSON 형태의 데이터를 파싱하고 Pydantic 스키마를 기반으로 검증한다.

* 필수 필드
* 데이터 타입
* 값 범위

### Tool

LLM이 외부 기능을 사용할 수 있도록 연결한다.

예:

* Web Search
* Calculation
* External API

### Tool Calling Flow

```text
@tool
  ↓
bind_tools()
  ↓
LLM
  ↓
response.tool_calls
  ↓
Tool 실행
  ↓
ToolMessage
  ↓
LLM 최종 응답
```

* `@tool`: Python 함수를 LLM Tool로 정의
* `bind_tools()`: 사용 가능한 Tool을 LLM에 전달
* `response.tool_calls`: LLM이 요청한 Tool 호출 정보 확인
* `ToolMessage`: Tool 실행 결과를 LLM에게 전달
* `messages + session_id`: 이전 대화 및 Tool 결과의 문맥 유지

# RAG Basics

## RAG

**RAG(Retrieval-Augmented Generation)**는 관련 자료를 검색한 뒤, 검색된 내용을 참고해 LLM이 답변하도록 하는 방식이다.

활용 예:

* 최신 정보
* 사내 문서
* 개인 문서

```text
질문 → 관련 자료 검색 → 검색 결과 + 질문 → LLM → 답변
```

## Embedding

Embedding은 텍스트를 숫자 벡터 형태로 변환하는 과정이다.

```text
Text
  ↓
Embedding
  ↓
[0.12, -0.54, 0.81, ...]
```

텍스트를 벡터로 표현하면 질문과 문서 사이의 의미적 유사성을 비교하여 관련 문서를 찾는 데 활용할 수 있다.
