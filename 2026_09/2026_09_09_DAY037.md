# ReAct Agent & Memory State

## ReAct Agent

**ReAct = Reasoning + Acting**

LLM이 사용자 질문을 분석하고 필요한 Tool을 선택해 실행한 뒤, 결과를 다시 확인하며 필요한 경우 추가 Tool을 호출하는 Agent 방식이다.

```text
사용자 질문
→ LLM 판단
→ Tool 호출
→ 결과 확인
→ 재판단
→ 최종 답변
```

## ReAct with LangGraph

주요 구성 요소:

- `MessagesState`: 대화 메시지 저장
- `chatbot`: LLM이 다음 행동 판단
- `ToolNode`: Tool 실행
- `tools_condition`: Tool 호출 또는 종료 분기

Tool 실행 후 다시 `chatbot`으로 돌아가는 반복 구조를 사용한다.

## `create_agent()`

ReAct 구조를 직접 `StateGraph`로 구성하지 않고 간단하게 Agent를 생성할 수 있다.

직접 구현 방식과 `create_agent()` 방식 모두 기본적으로 다음 흐름을 따른다.

```text
LLM 판단 → Tool 실행 → 결과 확인 → 재판단
```

## Product Search Agent

사용 Tool:

- `search_products()`: 키워드로 상품 검색 후 상품 ID 반환
- `get_product()`: 상품 ID를 이용해 가격과 재고 조회

실행 흐름:

```text
"무선 키보드 찾아줘"
→ search_products()
→ 상품 ID A100
→ get_product("A100")
→ 가격 39,000원 / 재고 12개
→ 최종 답변
```

`@tool` 함수에는 LLM이 Tool의 역할을 이해할 수 있도록 docstring을 작성한다.

## Memory State

### State

현재 그래프가 가지고 있는 데이터.

### Checkpointer / MemorySaver

State를 저장하고 복원하며 `thread_id`를 기준으로 같은 대화의 이전 상태를 이어서 사용할 수 있다.

### `thread_id`

각 대화의 State를 구분하는 값.

### Store

하나의 thread를 넘어 여러 대화에서 재사용할 사용자 정보를 저장한다.

### Summary

대화가 길어졌을 때 이전 내용을 요약하여 중요한 정보를 유지하는 방식.

```text
State
= 현재 그래프 데이터

Checkpointer
= State 저장/복원
= thread_id 기준 같은 대화 기억

Store
= 여러 thread에서 재사용할 정보 저장

Summary
= 긴 대화를 요약해서 기억
```
