# LangGraph Multi-Agent: Subgraph, Supervisor, Handoff

## Subgraph

LangGraph에서는 별도로 만든 Graph를 부모 Graph의 Node로 등록할 수 있다.

작은 작업 흐름을 독립된 Graph로 구성한 뒤 큰 Graph에 포함하여 사용할 수 있다.

### 장점

- Graph 재사용
- 역할별 개발 및 관리
- State 분리

```text
Parent Graph
    ↓
 Subgraph
    ↓
Next Node
```

Parent Graph와 Subgraph의 State 구조가 다르면 Wrapper를 사용하여 필요한 데이터를 변환할 수 있다.

---

## Multi-Agent

서로 다른 역할의 여러 Agent가 협력하여 하나의 목표를 처리하는 구조이다.

## Supervisor

Multi-Agent 시스템에서 사용자 요청과 현재 상태를 바탕으로 필요한 Subagent를 선택하고 전체 작업 흐름을 조정한다.

```text
Supervisor
├─ Research Agent
├─ Planning Agent
└─ Review Agent
```

---

## Handoff

현재 Agent가 다른 Agent에게 실행 제어권을 넘기는 방식이다.

LangGraph에서는 `Command`를 이용하여 State를 변경하고 다음 Node로 이동할 수 있다.

```text
Agent A
   ↓
Command
   ↓
Agent B
```

---

## Multi-Agent Practice

이번 실습에서는 각 Subagent 내부에 이전에 학습한 Agent 패턴을 결합했다.

```text
Supervisor
│
├─ Research Agent
│   └─ Orchestrator-Worker
│
├─ Planning Agent
│   └─ Plan-and-Execute
│
└─ Review Agent
    └─ Reflection / Evaluator-Optimizer
```

### Research Agent

- 조사 항목 생성
- 항목별 조사
- 결과 종합

### Planning Agent

- 사용자 조건과 조사 결과 입력
- 계획 단계 작성
- 최종 실행 계획 생성

### Review Agent

- 계획 평가
- 문제점 및 누락 확인
- 결과 개선

---

## 전체 흐름

```text
사용자
  ↓
Supervisor
  ↓
Research
  ↓ 조사 결과
Planning
  ↓ 계획
Review
  ↓ 개선 결과
Supervisor
  ↓
최종 답변
```

Supervisor는 전체 Agent 흐름을 관리하고, 각 Subagent는 자신의 역할에 맞는 Agent 패턴을 사용한다. Checkpointer를 연결하여 대화 State를 이어서 사용할 수 있도록 구성했다.
