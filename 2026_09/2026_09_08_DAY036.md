# LangGraph

LangGraph의 State, Node, Edge와 조건부 분기 및 반복 구조를 학습했다.

## Core Concepts

* **State**: 그래프 전체에서 공유하는 데이터
* **Node**: 실제 작업을 수행하는 함수
* **Edge**: Node 사이의 연결
* **START / END**: 그래프의 시작과 종료
* **Conditional Edge**: 결과에 따라 다음 Node를 선택
* **Loop**: 조건에 따라 이전 Node로 돌아가 작업 반복
* **Reducer**: State 값의 덮어쓰기 또는 누적 방식 결정

## Conditional Routing

라우팅 함수의 반환값에 따라 다음 Node를 선택할 때 `add_conditional_edges()`를 사용한다.

```text
write → review
          ├─ pass → END
          └─ rewrite → rewrite → review
```

## FakeListChatModel

`FakeListChatModel`을 이용해 실제 API를 호출하지 않고 미리 정의한 응답을 순서대로 반환하여 LangGraph 흐름을 테스트했다.

```text
부실한 응답
   ↓
review
   ↓
rewrite
   ↓
개선된 응답
   ↓
review
   ↓
pass
```

## LLM Injection

Graph를 Class로 구성하고 생성할 때 LLM을 전달하면 동일한 Graph 구조에서 실제 LLM과 Fake LLM을 교체하여 사용할 수 있다.

```python
class Graph:
    def __init__(self, llm):
        self.llm = llm

    def write(self):
        self.llm.invoke()
```
