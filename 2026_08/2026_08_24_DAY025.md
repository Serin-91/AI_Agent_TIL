# DAY 025 — Object-Oriented Programming

## OOP 핵심 개념

### 1. Encapsulation

데이터와 메서드를 하나의 클래스에 묶고, 중요한 데이터의 직접 접근을 제한하여 클래스 내부에서 관리한다.

```python
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount

    def get_balance(self):
        return self.__balance
```

---

### 2. Inheritance

부모 클래스의 속성과 메서드를 자식 클래스가 물려받아 재사용하고 확장한다.

```python
class Animal:
    def eat(self):
        print("밥을 먹습니다.")


class Dog(Animal):
    def bark(self):
        print("멍멍!")
```

---

### 3. Abstraction

공통으로 필요한 기능이나 규칙을 정의하고 실제 구현은 자식 클래스에 맡긴다.

```python
from abc import ABC, abstractmethod


class Payment(ABC):
    @abstractmethod
    def pay(self, amount):
        pass


class CardPayment(Payment):
    def pay(self, amount):
        print(f"카드 결제 완료: {amount}원")
```

---

### 4. Polymorphism

동일한 이름의 메서드를 호출하더라도 객체에 따라 서로 다른 동작을 수행할 수 있다.

```python
class Cat:
    def speak(self):
        return "야옹"


class Dog:
    def speak(self):
        return "멍멍"


for animal in [Cat(), Dog()]:
    print(animal.speak())
```

---

### 5. Composition

상속 대신 다른 클래스의 객체를 내부 구성 요소로 포함하여 기능을 사용한다.

```python
class Engine:
    def start(self):
        return "엔진 가동!"


class Car:
    def __init__(self):
        self.engine = Engine()

    def drive(self):
        print(self.engine.start())
        print("자동차가 달립니다.")
```

- Inheritance: **is-a 관계**
- Composition: **has-a 관계**

---

## OOP Design

여러 클래스를 역할에 따라 분리하고, 상속·추상 클래스·합성·다형성 등을 이용해 객체들이 서로 협력하도록 설계한다.

```text
클래스 분리
→ 역할 분담
→ 클래스 관계 설정
→ 객체 간 협력
```

### Summary

- Encapsulation: 데이터 접근 관리
- Inheritance: 부모 기능 재사용 및 확장
- Abstraction: 공통 규칙 정의
- Polymorphism: 같은 인터페이스, 다른 동작
- Composition: 다른 객체를 내부 구성 요소로 사용
