# Python 기초 학습

Python의 컨테이너 자료형과 반복문을 중심으로 기본 문법을 학습했습니다.

## 리스트와 튜플

```python
numbers = [10, 20, 30]
position = (10, 20)
```

* 리스트 `[]` : 값 수정 및 추가 가능
* 튜플 `()` : 생성 후 값 수정 불가

## 기본 연산

```python
count = 0
count += 1

age = 20

age == 20
age != 30
```

* `=` : 값 할당
* `==` : 같은지 비교
* `!=` : 다른지 비교
* `+=` : 기존 값에 값을 더해 다시 저장

## 입력과 출력

```python
name = input("이름: ")
print(name)
```

## `for` 반복문

```python
for i in range(5):
    print(i)
```

리스트의 값을 직접 반복할 수도 있습니다.

```python
fruits = ["apple", "banana", "orange"]

for fruit in fruits:
    print(fruit)
```

## 리스트 활용

```python
result = []

for i in range(5):
    result.append(i)
```

* `len()` : 데이터의 길이 또는 개수 확인
* `append()` : 리스트에 값 추가
* `enumerate()` : 번호와 값을 함께 가져오기

```python
for i, fruit in enumerate(fruits):
    print(i, fruit)
```

## `while` 반복문

조건이 참인 동안 반복합니다.

```python
count = 0

while count < 3:
    print(count)
    count += 1
```

* `for` : 반복 횟수가 정해져 있을 때
* `while` : 특정 조건이 만족되는 동안 반복할 때
