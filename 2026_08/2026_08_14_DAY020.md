## Function

함수 정의:

```python
def 함수이름():
    실행할 코드
```

- `def`: 함수 정의
- `return`: 함수 실행 결과 반환
- 함수는 필요할 때 여러 번 호출 가능

## 조건에 맞는 데이터 추출

```python
result = []

for data in 여러_데이터:
    if 조건:
        result.append(필요한_값)
```

기본 흐름:

```text
for
↓
if
↓
append()
```

`len()`은 데이터의 길이를 확인할 때 사용한다.

```python
if len(name) >= 3:
    result.append(name)
```

여러 조건:

```python
if len(username) >= 4 and age >= 19 and "@" in email:
```

`and`로 연결된 조건을 모두 만족해야 한다.

## 유지보수를 고려한 할인율 계산

```python
total * (1 - discount_rate)
```

할인율을 별도의 변수로 관리한다.

```python
def calculate_discount_rate(membership_grade):
```

멤버십 등급별 할인율을 별도의 함수에서 관리한다.

```python
return discount_rate_mapping.get(membership_grade, 0)
```

`get()`을 사용해 해당 멤버십 등급의 할인율을 가져오고,
등급이 존재하지 않으면 `0`을 반환한다.

→ 할인율 계산


→ 배송료 계산

```python
def calculate_checkout_price(my_cart, membership_grade):
```

→ 최종 결제 금액 계산
