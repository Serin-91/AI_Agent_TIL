# API 호출 및 데이터 처리

## API Request

```python
response = requests.get(
    url,
    headers=my_headers,
    params=my_params
)
```

- `url`: 요청할 API 주소
- `headers`: 인증정보 등의 부가정보
- `params`: 페이지 등 요청 조건
- `response`: 서버의 응답

## JSON Response

```python
data = response.json()
results = data.get("results")
```

API 응답을 Python 데이터로 변환한 뒤 필요한 값을 추출한다.

## 최대값 및 정렬

```python
max(data, key=lambda x: x["기준"])

sorted(
    data,
    key=lambda x: x["기준"],
    reverse=True
)
```

`key`를 이용해 비교·정렬 기준을 지정할 수 있다.

## List Comprehension

```python
simple_movies = [
    get_simple_movie(movie)
    for movie in movies
]
```

반복문과 리스트 추가 작업을 간결하게 표현할 수 있다.

## Pagination

데이터가 여러 페이지로 나뉜 경우 `page` 값을 변경하며 API를 반복 호출하고, 각 결과를 `extend()` 등으로 합칠 수 있다.

## ID 기반 상세 API 호출

```python

movie_detail = get_movie_by_id(movie_id)

```

```python

    url = f"https://api.themoviedb.org/3/movie/{movie_id}"
```

목록 API에서 객체의 ID를 얻은 뒤 해당 ID를 이용해 상세 API를 호출한다.

```text
목록 API
→ ID 추출
→ 상세 API 호출
→ 필요한 상세정보 추출
```

이 구조는 `/users → /users/{user_id}`처럼 다른 REST API에서도 활용할 수 있다.
