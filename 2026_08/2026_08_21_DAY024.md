# Python API & Class Study

## API

API 호출을 통해 외부 서버에 요청을 보내고 필요한 데이터를 받아올 수 있다.

## Class

클래스는 객체를 생성하기 위한 설계도이다.

```python
class Student:
    def __init__(self, name, student_id):
        self.name = name
        self.student_id = student_id
```

- `class`: 클래스 정의
- `__init__`: 객체 생성 시 실행되는 초기화 메서드
- `self`: 현재 객체
- 인스턴스 변수: 객체별로 저장되는 값
- 클래스 변수: 같은 클래스의 객체들이 공유하는 값

## Property / Setter

- `property`: 메서드를 속성처럼 접근할 수 있도록 한다.
- `setter`: 값을 할당할 때 검사나 추가 로직을 수행할 수 있다.

## Method Types

- 인스턴스 메서드: 객체를 대상으로 동작
- 클래스 메서드: 클래스 자체를 대상으로 동작
- 정적 메서드: 클래스나 객체 상태와 무관한 기능 수행

## Inheritance

기존 클래스의 속성과 메서드를 새로운 클래스에서 재사용하거나 확장할 수 있다.

```python
class A:
    pass

class B(A):
    pass
```

`B`는 `A`를 상속받는다.

다중 상속을 이용하면 여러 부모 클래스의 기능을 하나의 자식 클래스에서 사용할 수도 있다.

```python
class SmartDevice(Speaker, Camera):
    pass
```

## `super()`

부모 클래스의 메서드를 자식 클래스에서 호출할 때 사용한다.

## Overriding

부모 클래스에 있는 메서드를 자식 클래스에서 같은 이름으로 다시 정의하는 것을 오버라이딩이라고 한다.
