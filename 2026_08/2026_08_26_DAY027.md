# Gemini Function Calling

## Function Calling

Gemini가 사용자 질문을 분석하여 필요한 함수를 선택하고 함수 호출에 필요한 인자를 결정하는 기능을 학습했다.

실제 외부 함수 실행은 Gemini가 아닌 **사용자 애플리케이션**이 담당한다.

```text
User
 ↓
Gemini
 ↓
Function Call
 ↓
Python Function
 ↓
Function Result
 ↓
Gemini
 ↓
Final Response
```

## 주요 개념

- **Schema**: 함수의 용도와 필요한 인자를 모델에게 설명하는 구조
- **Tool 등록**: Gemini가 사용할 수 있는 함수를 등록
- **Tool 선택**: 여러 함수 중 질문에 필요한 함수를 Gemini가 선택
- **Function Result**: Python 함수 실행 결과를 다시 Gemini에게 전달
- **연속 Tool 호출**: 첫 번째 Tool 결과를 이용해 다음 Tool을 호출
- **Agent Loop**: 판단 → Tool 호출 → 결과 → 재판단 과정을 반복

## Multi-Tool Example

```text
사용자: "O100 주문의 배송비를 알려줘"

get_order("O100")
        ↓
주문 지역 / 주문 금액
        ↓
get_shipping_fee(region, order_amount)
        ↓
배송비 결과
        ↓
최종 응답
```

Python + Gemini API를 이용하여 여러 Tool을 등록하고 Function Calling 및 연속 Tool 호출 구조를 직접 구현했다.

## Gemini API 핵심 정리

- **Streaming**: 응답이 생성되는 동안 결과를 여러 조각으로 순차적으로 전달
- **Structured Output**: 모델의 최종 응답이 지정한 JSON Schema를 따르도록 구성
- **Function Calling**: Gemini가 함수와 인자를 선택하며 실제 함수 실행은 사용자 애플리케이션이 담당
