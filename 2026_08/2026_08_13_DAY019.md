# Python Basics

## 학습 내용

### 조건에 맞는 데이터 추출

~~~python
result = []

for data in 여러_데이터:
    if 조건:
        result.append(필요한_값)
~~~

- `for`: 여러 데이터를 하나씩 확인
- `if`: 원하는 조건인지 확인
- `append()`: 필요한 값을 리스트에 추가

---

## 중첩 데이터와 중첩 for문

리스트 안에 딕셔너리가 들어가거나,
딕셔너리 안에 다시 리스트가 들어갈 수 있다.

~~~python
order["items"]
item["status"]
item["name"]
~~~

여러 주문과 각 주문 안의 상품을 확인할 때는 `for`문을 중첩해서 사용한다.

~~~python
for order in orders:
    for item in order["items"]:
~~~

---

## 가격 조건으로 상품 찾기

~~~python
if product["price"] >= 50000:
    result.append(product["name"])
~~~

`price`가 50,000 이상인 상품의 `name`을 리스트에 저장한다.

---

## 품절 상품 찾기

~~~python
if item["status"] == "out_of_stock":
    out_of_stock_items.append(item["name"])
~~~

품절 상품이 포함된 주문을 확인하기 위해 `True / False` 값을 사용한다.

~~~python
has_out_of_stock = False

if item["status"] == "out_of_stock":
    has_out_of_stock = True

if has_out_of_stock == True:
    problematic_orders.append(order["order_id"])
~~~

한 주문에 품절 상품이 여러 개 있어도 `order_id`는 한 번만 저장한다.

## Dictionary

특정 키에 대응하는 값 가져오기:

~~~python
student = {'name': '민지', 'age': 20}
student['name']
~~~

값 변경:

~~~python
data['a'] = 10
~~~

`data` 딕셔너리에서 `'a'` 키의 기존 값 `1`을 `10`으로 변경한다.

추가 학습 내용:

- 딕셔너리 `scores`
- `for + if + 합계`
- 리스트 안의 딕셔너리 형태

중첩 데이터:

