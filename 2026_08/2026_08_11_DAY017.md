## Python 기초

Python 기본 문법과 프로그램의 흐름을 구성하는 기초 개념을 학습했습니다.

### 변수와 자료형

```python
name = "Serin"
age = 20
height = 165.5
is_student = True
```

* 변수 / 할당 / 식별자 / 리터럴
* 재할당 / 동시 할당
* `int`, `float`, `str`, `bool`

### 입력과 조건문

```python
age = int(input("나이를 입력하세요: "))

if age >= 20:
    print("성인입니다.")
else:
    print("미성년자입니다.")
```

* `input()` / `print()`
* `if` / `elif` / `else`
* 비교 및 논리 연산자

### 리스트와 반복문

```python
fruits = ["사과", "바나나", "포도"]

for fruit in fruits:
    print(fruit)
```

* 리스트 생성 및 값 접근
* `append()`를 이용한 값 추가
* `for` 반복문

### 개발 환경 단축키

* `Alt + Shift + 방향키` : 현재 줄 복사
* `Ctrl + D` : 같은 변수나 단어 여러 개 선택
