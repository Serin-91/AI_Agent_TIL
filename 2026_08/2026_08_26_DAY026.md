# Gemini API & Structured Output

## Google SDK

Gemini SDK를 사용해 Python에서 모델을 호출하는 기본 방법을 학습했다.

```python
response = client.models.generate_content(
    model="gemini-3.6-flash",
    contents="안녕"
)
```

## Interactions API

Gemini와 요청 및 응답을 주고받는 기본 구조를 학습했다.

- 문자열 input
- Content 배열을 이용한 복수 콘텐츠 입력
- Step 배열을 이용한 대화 이력 전달
- `store=False`를 이용한 비저장 방식
- `output_text`를 이용한 텍스트 응답 추출

## Structured Output

일반 텍스트 응답은 형식이 일정하지 않아 프로그램에서 처리하기 어려울 수 있다.

이를 해결하기 위해 응답 구조를 미리 정의하고 JSON 형식으로 받는 Structured Output 방식을 학습했다.

### Pydantic

- `BaseModel`: 응답 데이터 구조 정의
- 타입 힌트: 필드 자료형 지정
- `Literal`: 허용 가능한 선택지 제한
- `Field`: 길이 등 세부 조건 설정
- `ConfigDict(extra="forbid")`: 정의되지 않은 추가 필드 차단

### JSON Schema

Pydantic 모델을 Gemini가 사용할 수 있는 JSON Schema로 변환하는 방법을 학습했다.

- `model_json_schema()`
- `response_format`
- `mime_type="application/json"`

### JSON Parsing & Validation

- `json.loads()`: JSON 문자열을 Python 데이터로 변환
- `model_validate()`: Pydantic 규칙에 맞는 데이터인지 검증
- `ValidationError`: 검증 실패 처리

## 실습

고객 문의를 다음 구조로 분류하는 문의 자동 분류기를 구현했다.

```text
category
urgency
summary
```

전체 처리 흐름:

```text
사용자 문의
→ Gemini API
→ Structured JSON Response
→ json.loads()
→ Pydantic Validation
→ Python 프로그램에서 활용
```
