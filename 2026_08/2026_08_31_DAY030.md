# Python List & Loop Review

## List

여러 데이터를 순서대로 저장하는 자료형이다.

```python
numbers = [10, 20, 30]
```

Python의 list index는 `0`부터 시작한다.

```python
numbers[0]  # 10
numbers[1]  # 20
```

값을 수정할 수도 있다.

```python
numbers[1] = 99
```

---

## `len()`

리스트의 데이터 개수를 반환한다.

```python
len(numbers)
```

마지막 index는 다음과 같이 구할 수 있다.

```python
len(numbers) - 1
```

---

## `for`

리스트의 값을 하나씩 반복한다.

```python
numbers = [10, 20, 30]

for num in numbers:
    print(num)
```

---

## `range()`와 index

index가 필요한 경우 `range()`와 `len()`을 함께 사용할 수 있다.

```python
for i in range(len(numbers)):
    print(numbers[i])
```

---

## `for + if`

반복하면서 조건에 맞는 데이터만 처리할 수 있다.

```python
response_times = [180, 520, 95, 870]

for time in response_times:
    if time >= 500:
        print(time)
```

---

## `while`

조건이 참인 동안 반복한다.

```python
i = 1

while i <= 5:
    print(i)
    i += 1
```

---

## `break`

반복문을 즉시 종료한다.

```python
while True:
    if i == 5:
        break
```

---

## Nested Loop

2차원 리스트처럼 여러 층으로 구성된 데이터를 반복할 때 중첩 반복문을 사용할 수 있다.

```python
mat = [
    [1, 2, 3],
    [4, 5, 6]
]

for row in mat:
    for value in row:
        print(value)
```

2차원 리스트의 값은 두 개의 index로 접근할 수 있다.

```python
mat[1][2]  # 6
```

```text
mat[i][j]

i → 행의 위치
j → 해당 행 안의 값 위치
```

## 핵심 정리

* `list` : 여러 데이터 저장
* `index` : 데이터 위치 확인
* `len()` : 데이터 개수 확인
* `for` : 데이터를 하나씩 반복
* `for + if` : 조건에 맞는 데이터 처리
* `range(len())` : index가 필요한 반복
* `while` : 조건 기반 반복
* `break` : 반복 종료
* 중첩 `for` : 여러 층의 데이터 반복
