# Financial News Agent

## Troubleshooting

### Gemini Response Truncation

Gemini가 뉴스 8개를 한 번에 분석하면서 응답이 중간에 잘리는 문제가 발생했다.

적용한 변경 사항:

* 분석 기사 수: 8개 → 5개
* 출력 한도: 4096 → 8192
* 기사 요약: 1문장, 100자 이하

### Output Parser Failure

Gemini의 실제 응답 구조가 검증 코드의 예상 형식과 달라 파싱이 반복적으로 실패했다.

Output Parser는 작은 형식 차이에도 전체 응답을 실패 처리하고, 잘린 응답을 복구하지 못했다.

Output Parser를 제거하고 Code 노드에서 응답을 직접 파싱하고 검증하도록 수정했다.
