# Python Basics & Gemini Async Request

## Gemini 비동기 요청

학습 주제:

- Coroutine Function (`async def`)
- Semaphore
- Work Queue

비동기 작업에서는 여러 요청의 실행 흐름과 동시에 처리되는 작업 수를 관리하는 구조를 학습했다.

- **Coroutine Function**: `async def`로 정의하는 비동기 함수
- **Semaphore**: 동시에 실행되는 작업 수 제한
- **Queue**: 처리할 작업을 보관하고 순서대로 관리

## Python 기초 복습

복잡한 알고리즘보다 우선 다음 기본 자료구조와 제어 흐름을 중심으로 복습했다.

- `for`
- `List`
- `Dictionary`

### List / Dictionary

```python
scores = [90, 80, 70]
print(scores[1])
```

List는 위치(index)를 이용해 값을 가져온다.

```python
scores = {"Kim": 90, "Lee": 80}
print(scores["Kim"])
```

Dictionary는 `key:value` 구조로 값을 저장한다.

Dictionary의 key와 value를 함께 순회할 때는 `.items()`를 사용한다.

```python
for name, score in scores.items():
    print(name, score)
```

리스트의 값 포함 여부는 `in`으로 확인할 수 있다.

```python
2 in [1, 2, 3]
```

## 조건문

함수 매개변수의 기본값은 `=`로 지정한다.

```python
def hello(name="Kim"):
    print(name)
```

`if → elif → else`는 위에서부터 조건을 검사하며 처음으로 `True`가 된 블록을 실행한다.

## Instance Variable

객체별로 독립적인 값을 저장할 때 `self.변수명` 형태의 인스턴스 변수를 사용한다.

```python
class Account:
    def __init__(self, balance):
        self.balance = balance
```

각 `Account` 객체는 서로 다른 `balance` 값을 가질 수 있다.

## Python 기본 동작

```python
set(values)      # 중복 제거
sorted(values)   # 정렬
```

빈 리스트 `[]`는 조건식에서 `False`로 평가된다.

```python
if items:
    ...
```

함수 안에서 생성한 변수는 기본적으로 해당 함수의 지역변수(Local Variable)가 된다.

## 반복 흐름

```python
continue
```

현재 반복만 건너뛰고 다음 반복으로 진행한다.

```python
return
```

현재 함수를 종료한다.

### 핵심

```text
continue → 현재 반복만 건너뜀
return   → 함수 자체 종료
```

Python 기초 학습에서는 문법 암기보다 **데이터와 코드가 어떤 순서로 이동하고 실행되는지 흐름을 읽는 연습**에 집중한다.
