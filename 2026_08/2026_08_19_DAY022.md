# Algorithm & REST API

## Algorithm Practice

프로그래머스에서 알고리즘 문제 풀이를 학습했다.

- 올바른 괄호
- 다리를 지나는 트럭

알고리즘 문제는 문제의 동작을 작은 단계로 나눈 뒤 이를 코드로 표현하는 방식으로 접근한다.

---

## REST API

REST API의 주요 특징:

- Client-Server 분리
- Stateless
- Cacheable
- Layered System
- Uniform Interface

REST API에서는 **URL로 리소스를 식별하고 HTTP 메서드로 작업을 표현한다.**

---

## API Endpoint

API 엔드포인트는 API가 특정 리소스에 접근할 수 있도록 외부에 노출한 주소이다.

```http
GET /users
```

여기서 `/users`는 사용자 리소스에 접근하는 엔드포인트이다.

### Endpoint Design

리소스 중심으로 주소를 설계한다.

```text
❌ /get_users
❌ /create_users

✅ /users
```

주요 원칙:

- 복수 명사 사용
- `/`를 이용한 계층 관계 표현
- URL에는 동작보다 리소스를 표현

---

## HTTP Method & Path

데이터 조회에는 주로 `GET`을 사용한다.

```http
GET /users
```

- `GET` → 수행할 작업
- `/users` → 접근할 리소스

URL에서 자원을 식별하는 부분은 **Path(경로)** 이다.

```text
URL → 리소스 식별
HTTP Method → 작업 표현
```
