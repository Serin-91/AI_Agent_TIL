## 2차원 배열 생성

```python
mat = [[0] * m for i in range(n)]
```

`n`행 × `m`열 크기의 2차원 배열을 0으로 초기화한다.

예:

```python
n = 2
m = 3

mat = [[0] * m for i in range(n)]

# [
#     [0, 0, 0],
#     [0, 0, 0]
# ]
```

## 2차원 배열의 값 접근

```python
arr = [
    [10, 20, 30],
    [40, 50, 60],
    [70, 80, 90]
]

print(arr[1][2])  # 60
```

Python의 인덱스는 `0`부터 시작한다.

- `arr[1]` → `[40, 50, 60]`
- `arr[1][2]` → `60`

## 시간복잡도

입력 크기 `n`이 증가할 때 알고리즘의 작업량이 어떻게 증가하는지를 나타내는 개념이다.

데이터가 커졌을 때 코드의 실행 효율을 판단하는 데 사용한다.

## IndexError

```python
n = 5
arr = [0] * n

for i in range(n):
    arr[i + 1] = i
```

`arr`의 사용 가능한 인덱스는 `0 ~ 4`이다.

마지막 반복에서:

```python
i = 4
arr[i + 1] = arr[5]
```

가 되어 존재하지 않는 위치에 접근하므로 `IndexError`가 발생한다.

```text
리스트의 길이 = n
사용 가능한 인덱스 = 0 ~ n-1
```
